# Исходный код реализации

Разместите здесь реализацию языка.

Рекомендуемая структура:

```text
src/
  lexer
  parser
  ast
  interpreter или compiler
  runtime
  errors
```

Можно использовать другую структуру, если она понятна и описана в `README.md`.

Минимально в реализации должны быть:

- лексический анализ;
- синтаксический анализ;
- внутренняя структура программы, например AST;
- выполнение или компиляция программы;
- обработка ошибок.
