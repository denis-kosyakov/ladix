# Ladix — Go-модуль

Здесь живёт исходный код языка Ladix (Go-модуль `github.com/denis-kosyakov/ladix`):
лексер, парсер, AST, семантика, интерпретатор, движок процессов и CLI (`cmd/ladix/`).

Команды разработчика выполняются **из этого каталога** (`src/`):

```sh
# сборка бинарника в корень репозитория (мост -o ../ladix)
go build -o ../ladix ./cmd/ladix

# тесты всех пакетов
go test ./...

# статический анализ
go vet ./...
```

Запуск собранного бинарника и полный CLI-справочник (команды, флаги, коды возврата),
примеры и скоуп v1 — в корневом [README.md](../README.md). Бинарник `./ladix` запускают
из **корня** репозитория, где лежат `examples/` и `data/`.

Навигация и процедуры воркспейса → [AGENTS.md](../AGENTS.md).
