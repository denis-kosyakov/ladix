# Проект: собственный язык программирования

Этот репозиторий является стартовым шаблоном для проекта по разработке собственного языка программирования.

Ваша задача: спроектировать и реализовать небольшой, но цельный язык программирования. В результате должен получиться проект, который можно собрать, запустить, протестировать и понять по документации.

Высоко оценивается не количество возможностей, а качество целого решения: понятный синтаксис, предсказуемое поведение, работающая реализация, хорошие ошибки, тесты и аккуратная документация.

## Что нужно сделать

Минимально язык должен поддерживать:

- идентификаторы, литералы, операторы, ключевые слова и комментарии;
- переменные: объявление, присваивание, чтение, область видимости;
- выражения: арифметика, сравнения, логика, приоритет операторов, скобки;
- управляющие конструкции: условие, цикл, блоки кода;
- функции: объявление, параметры, вызов, возвращаемое значение, локальные переменные;
- вывод данных, например `print`;
- понятные сообщения об ошибках с номером строки.

Подробные требования находятся в [TASK.md](TASK.md).

## Структура проекта

```text
.
├── README.md
├── TASK.md
├── SPEC.md
├── CHECKLIST.md
├── examples/
├── tests/
└── src/
```

## Что нужно заполнить

1. Обновите этот `README.md`: добавьте название языка, описание идеи, инструкции запуска и тестирования.
2. Заполните [SPEC.md](SPEC.md): опишите синтаксис, грамматику, типы, семантику и ошибки.
3. Реализуйте язык в папке `src/`.
4. Добавьте примеры программ в `examples/`.
5. Добавьте автоматические тесты в `tests/`.
6. Проверьте проект по [CHECKLIST.md](CHECKLIST.md).

## Как запускать

Замените этот раздел своими командами.

Пример:

```bash
# запуск программы
<your-command> examples/hello.lang

# запуск тестов
<your-test-command>
```

## Минимальные примеры

Синтаксис файлов в `examples/` приведен только как пример. Вы можете изменить его под свой язык, но смысл программ должен сохраниться.
