# Стандартная библиотека Ladix — полный реестр

> Полный реестр стандартной библиотеки. Обзор по группам — SPEC §8.

Документ перечисляет все встроенные функции v1: имя, сигнатуру (типы аргументов и
результата — `Целое`/`Дробное`/`Строка`/`Булево`/`Пусто`/`Длительность`/`Период`/`Дата`/
`Список`/`Запись`/`Любой`), поведение, арность и ошибки. В конце — алфавитный указатель.

Сигнатуры записаны как `имя(параметр: Тип, …) → ТипРезультата`. Где параметр принимает
несколько типов — они перечислены через `|`. `Любой` означает «значение любого типа».

## Общие правила встроенных функций

- Реализованы движком (Go), не на Ladix. Пользователь их тела не видит и не переопределяет
  (только затеняет с предупреждением, см. §6).
- **Чистота.** Все встроенные, кроме `печать` и функций-запросов состояния процессов
  (см. «Процессы и домен»), — чистые (без побочных эффектов), детерминированные при
  фиксированном входе. Исключения детерминизма — `сегодня()`/`вчера()`/`завтра()` (зависят
  от системной даты) и процессные запросы (зависят от Store).
- **Мутация.** Единственная встроенная-мутатор — `добавить` (мутирует список, см. §4).
  Все остальные операции над списками (`соединить`, `срез`, `копия`, `обратить`,
  `сортировать`) возвращают **новый** список и оригинал не трогают.
- **Арность.** У функций фиксированной арности нарушение ловится на семантике; у вариативных
  и перегруженных (`печать`, `диапазон`, `дата`, `длина`) — в рантайме реализацией.
- **Типы аргументов** не проверяются на семантике (динамическая типизация, см. §4):
  несовместимый тип обнаруживается в рантайме первой же операцией над аргументом. Сообщение —
  стандартная ошибка типа с номером строки и колонкой (см. §13).

## Вывод

| Сигнатура | Поведение |
|---|---|
| `печать(значение: Любой, …) → Пусто` | **Вариативная.** Печатает строковые представления аргументов (см. «Строковое представление значений») через один пробел, в конце — перевод строки. `печать()` печатает пустую строку. Возвращает `пусто`. Единственный штатный канал вывода Ladix-программы. |

```ladix
печать("итог:", сумма(заказы), "₽")     # итог: 600 ₽
печать(пусто)                            # пусто
```

## Преобразование типов

Все — фиксированной арности (кроме `дата`, см. «Дата и длительность»).

| Сигнатура | Поведение |
|---|---|
| `строка(x: Любой) → Строка` | Строковое представление любого значения (см. «Строковое представление значений»). Всегда успешно. |
| `целое(x: Дробное\|Строка\|Булево\|Целое) → Целое` | Дробное → отсечение дробной части; Строка → парсинг целого (`"42"`→42; `"3.14"` или мусор → ошибка); Булево → 1/0; Целое → как есть. Иначе ошибка типа. |
| `дробное(x: Целое\|Строка\|Булево\|Дробное) → Дробное` | Целое → `n.0`; Строка → парсинг (`"3.14"`→3.14); Булево → 1.0/0.0. Иначе ошибка типа. |
| `число(x: Строка\|Целое\|Дробное) → Целое\|Дробное` | Строка → парсинг с автовыбором `Целое`/`Дробное`; `Целое`/`Дробное` → как есть. Иначе ошибка типа. |
| `булево(x: Любой) → Булево` | Мягкое (Python-truthiness): `0`, `0.0`, `""`, `[]`, `пусто`, `ложь` → `ложь`; всё остальное → `истина`. Только при явном вызове; в условиях `если`/`пока` truthiness не действует (см. §4). |
| `тип(x: Любой) → Строка` | Имя типа: `"Целое"`, `"Дробное"`, `"Строка"`, `"Булево"`, `"Пусто"`, `"Длительность"`, `"Период"`, `"Дата"`, `"Список"`, `"Запись"` (см. §4). |

## Агрегаты

Работают над `Список`. В контексте `метрика.агрегат:` применяются к списку значений поля,
спроецированному движком (см. §10). Как обычные функции — над любым списком.

| Сигнатура | Поведение |
|---|---|
| `сумма(s: Список) → Целое\|Дробное` | Сумма элементов. Все элементы должны быть числами (`Целое`/`Дробное`), иначе ошибка типа. Есть хотя бы один `Дробное` → результат `Дробное`. Пустой список → `0` (`Целое`). |
| `количество(s: Список) → Целое` | Число элементов. Для списка тождественно `длина(s)`; имя `количество` — идиоматичное в метриках. |
| `среднее(s: Список) → Дробное` | Среднее арифметическое чисел. Пустой список → ошибка `среднее: список пуст`. Нечисловой элемент → ошибка типа. |
| `мин(s: Список) → Любой` | Минимальный элемент. Элементы взаимно сравнимы по `<` (все `Целое`/`Дробное`, либо все `Строка`, либо все `Дата`; см. §4), иначе ошибка типа. Пустой список → ошибка `мин: список пуст`. |
| `макс(s: Список) → Любой` | Максимальный элемент. Правила те же, что у `мин`. Пустой список → ошибка `макс: список пуст`. |

`мин`/`макс` принимают **только список**: для двух значений — `мин([a, b])`. Двухаргументной
формы в v1 нет.

## Списки

`s[i]` (индексация) и `длина` описаны в §4 и в «Строки» ниже; здесь — функции над списками.

| Сигнатура | Поведение |
|---|---|
| `длина(s: Список\|Строка) → Целое` | Число элементов списка или рун строки. Иной тип → ошибка типа. |
| `добавить(s: Список, x: Любой) → Пусто` | **Мутирует** `s` (добавляет `x` в конец). Возвращает `пусто`. Во время активной итерации `для` над `s` — ошибка (см. §7). |
| `соединить(s1: Список, s2: Список) → Список` | **Новый** список = элементы `s1`, затем `s2`. Оригиналы не меняются. |
| `срез(s: Список, i: Целое, j: Целое) → Список` | **Новый** список из элементов `[i, j)`. Требует `0 ≤ i ≤ j ≤ длина(s)`, иначе ошибка `срез: индексы вне диапазона`. |
| `содержит(s: Список, x: Любой) → Булево` | `истина`, если какой-то элемент `== x` (равенство по §4). |
| `найти(s: Список, x: Любой) → Целое` | Индекс первого элемента `== x`, или `-1`, если такого нет. |
| `копия(s: Список) → Список` | **Поверхностная** копия (новый список, те же ссылки на вложенные объекты). Для snapshot-итерации (см. §7). |
| `обратить(s: Список) → Список` | **Новый** список в обратном порядке. |
| `сортировать(s: Список) → Список` | **Новый** список по возрастанию (`<`), устойчиво. Элементы взаимно сравнимы (как у `мин`/`макс`), иначе ошибка типа. |
| `диапазон(stop: Целое) → Список` | `[0, 1, …, stop-1]`. `stop ≤ 0` → `[]`. |
| `диапазон(start: Целое, stop: Целое) → Список` | `[start, …, stop-1]`. `start ≥ stop` → `[]`. Третья форма (с шагом) — не в v1 (см. §12). |

## Строки

Индексация `s[i]` и конкатенация `+` — операторы (см. §4 и §5), не функции.

| Сигнатура | Поведение |
|---|---|
| `длина(s: Строка\|Список) → Целое` | Число рун (для строки); перегружена со списком (см. «Списки»). |
| `подстрока(s: Строка, i: Целое, j: Целое) → Строка` | Подстрока из рун `[i, j)`. Требует `0 ≤ i ≤ j ≤ длина(s)`, иначе ошибка `подстрока: индексы вне диапазона`. Замена срезов `s[i:j]`, которых нет (см. §4, §12). |

Поиск подстроки, смена регистра, split/trim — **не в v1** (минимальный объём, см. §12).

## Дата и длительность

Аксессоры компонент даты и календарные сдвиги — **v2** (см. §4, §12).

| Сигнатура | Поведение |
|---|---|
| `дата(год: Целое, месяц: Целое, день: Целое) → Дата` | Конструктор. Невалидная дата (например, `дата(2026, 13, 1)`) → ошибка `дата: некорректные год/месяц/день`. |
| `дата(s: Строка) → Дата` | Парсинг `"YYYY-MM-DD"` или `"YYYY-MM-DDTHH:MM:SS"` (время отбрасывается, см. §4). Мусор → ошибка. |
| `дата(пусто) → Пусто` | Null-пропагация: `дата(пусто) == пусто`. Делает `по_дате: дата(поле)` толерантным к записям без даты — поле отсутствует → `пусто` → запись вне окна, без падения метрики (см. §10). |
| `сегодня() → Дата` | Текущая системная дата. |
| `вчера() → Дата` | `сегодня()` − `1дн`. |
| `завтра() → Дата` | `сегодня()` + `1дн`. |
| `длительность(значение: Целое, единица: Строка) → Длительность` | Конструктор. `единица` ∈ `"сек"`, `"мин"`, `"час"`, `"дн"`, `"нед"`, `"мес"` (набор — см. §2; семантика и ограничение `мес` — см. §4). Иная → ошибка `длительность: неизвестная единица 'XYZ'`. `длительность(5, "мин") == 5мин`. |
| `в_секундах(d: Длительность) → Целое` | Перевод в секунды. Определён для `сек`/`мин`/`час`/`дн`/`нед` (фиксированные единицы). Для `мес` → ошибка `в_секундах: месяцы не приводятся без даты-якоря` (см. §4). |
| `в_минутах(d: Длительность) → Целое` | Аналогично, для тех же единиц. |
| `в_часах(d: Длительность) → Целое` | Аналогично. |
| `в_днях(d: Длительность) → Целое` | Аналогично (`нед`→×7). `мес` → та же ошибка `в_днях: месяцы не приводятся без даты-якоря`. |

Арифметика `Дата`/`Длительность` (`Дата + Длительность`, `Дата - Дата`,
`Длительность + Длительность` и т.д.) — операторы, описаны в §4 и §5, не функции.

## Процессы и домен

Эти функции обращаются к движку процессов и Store. Их **сигнатуры** фиксированы здесь для
полноты поверхности вызова; **семантика, точный перечень статусов и поля Записей** — в §11
«Процессы и триггеры» и `docs/execution-model.md`.

| Сигнатура | Назначение |
|---|---|
| `статус_процесса(id: Строка) → Строка` | Статус инстанса по идентификатору из `запустить процесс` (см. §11). Множество статусов: `"создан"`, `"выполняется"`, `"ожидает"`, `"выполнен"`, `"провален"`, `"отменён"`. |
| `состояние_процесса(id: Строка) → Запись` | Текущие переменные процесса как `Запись` (см. §4). Отсутствующий `id` → ошибка `процесс 'id' не найден`. |
| `задачи_пользователя(исполнитель: Строка) → Список` | Список `Запись`-задач, назначенных исполнителю (структура задачи — см. §11). |

**Не функции, а действия шага:** `вызвать Ident(…)` и `уведомить Ident(…)` — это действия
шага процесса (см. §3, §11), не вызовы стандартной библиотеки. Их целевые имена — внешние
системные стабы; в v1 печатают в лог. Семантика, в т.ч. обработка ошибок `вызвать`, — см. §11.

## Строковое представление значений

Используется в `строка(x)` и `печать`. Согласовано с §4.

| Тип | Представление | Пример |
|---|---|---|
| Целое | десятичная запись | `42`, `-5` |
| Дробное | человекочитаемая запись с точкой | `3.14`, `1.0` |
| Строка | сам текст, без кавычек | `привет` |
| Булево | `истина` / `ложь` | `истина` |
| Пусто | `пусто` | `пусто` |
| Длительность | значение + суффикс | `3дн`, `5мин` |
| Период | имя константы | `ежемесячно` |
| Дата | ISO `YYYY-MM-DD` | `2026-05-30` |
| Список | `[` элементы через `, ` (рекурсивно через `строка`) `]` | `[1, две, истина]` |
| Запись | `{` `поле: значение` через `, ` `}` | `{номер: 7, сумма: 1000}` |

> Внутри `Список`/`Запись` строки печатаются **без** кавычек (как и на верхнем уровне).
> Различение «строка `два` против идентификатора» — задача отладки через `тип(x)`, не вывода.

## Глубина рекурсии

Рекурсия поддерживается (см. §8). Чтобы убегающая рекурсия не валила процесс паникой
переполнения Go-стека, интерпретатор ведёт явный счётчик глубины вызовов и при превышении
лимита бросает штатную рантайм-ошибку (см. §13):

```
Ошибка в строке N, колонка M: превышена максимальная глубина вызовов (10000).
Возможна бесконечная рекурсия.
```

Лимит по умолчанию — **10000**, конфигурируется флагом `--max-depth` (см. README, раздел CLI).
Лимит распространяется и на встроенные функции, вызывающие пользовательские (в v1 таких нет,
но правило общее).

## Алфавитный указатель встроенных функций

Все встроенные затеняемы с предупреждением (см. §6); все, кроме помеченных, — фиксированной
арности.

`булево`, `в_днях`, `в_минутах`, `в_секундах`, `в_часах`, `вчера`, `дата` (1\|3 арг),
`диапазон` (1\|2 арг), `длина` (Строка\|Список), `длительность`, `добавить`, `дробное`,
`завтра`, `задачи_пользователя`, `количество`, `копия`, `макс`, `мин`, `найти`, `обратить`,
`печать` (вариативная), `подстрока`, `сегодня`, `соединить`, `содержит`, `состояние_процесса`,
`сортировать`, `среднее`, `срез`, `статус_процесса`, `строка`, `сумма`, `тип`, `целое`,
`число`.

Итого **35 встроенных функций** в v1. Период-константы (`ежедневно`/…/`ежегодно`, см. §4) —
предопределённые **значения**, не функции, и в счёт не входят.
