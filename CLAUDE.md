# Ladix — инструкции для Claude Code

Ladix — DSL (кириллические ключевые слова) для системы управления бизнесом «Уклад»: метрики/KPI,
процессы с человеком-в-цикле, триггеры. Go-модуль `github.com/denis-kosyakov/ladix` в корне репо,
без CGO, единственная зависимость — `modernc.org/sqlite`. v2 финализирована; развитие аддитивно.

Onboarding и раскладка — **[AGENTS.md](AGENTS.md)**. Язык — `SPEC.md`. Модули — `ARCHITECTURE.md`.
Канонические модели поведения — `docs/*-model.md` (источник истины, Принцип IX).

## Процесс разработки — OpenSpec

Фичи ведутся через **OpenSpec** (`openspec/`, схема `spec-driven`). Контекст проекта, конспект
Конституции и правила артефактов — в `openspec/config.yaml`; читать через `openspec context`.

- `openspec/specs/<capability>/spec.md` — живые спеки «что система делает сейчас».
- `openspec/changes/<name>/` — предложение изменения: `proposal.md` → `specs/` (дельта) →
  `design.md` → `tasks.md`.
- Команды: `/opsx:explore` (подумать) → `/opsx:propose` или `/opsx:new`+`/opsx:continue`
  (планирование, код НЕ трогать) → `/opsx:apply` (реализация по tasks.md) → `/opsx:verify` →
  `/opsx:archive` (дельты вливаются в `openspec/specs`). `openspec validate --all` перед архивом.
- Одна фича — одна ветка `NNN-<kebab>` от `master`; нумерация продолжает `specs/` (следующая — 030).

`specs/001–029` и `.specify/` — **архив SpecKit** предыдущих фич; новые фичи там не создавать.
Конституция по-прежнему в `.specify/memory/constitution.md` (9 принципов), её конспект — в
`openspec/config.yaml`; при расхождении приоритет у полного текста конституции.

## Инварианты, которые проверяются в каждой фиче

- Границы диффа объявляются в proposal (какие пакеты меняются, какие с ПУСТЫМ диффом) и не расширяются.
- 0 новых зависимостей / ключевых слов / builtins / кодов ошибок — если не сказано иное явно.
- Тексты пользовательских сообщений — русские, дословно по SPEC §13; не переформулировать.
- Каждый инвариант закрыт тестом-замком, краснеющим при удалении гарда (мутпроба).
- Время — только через инжектируемые часы (`engine.Clock`/`FixedClock`); детерминированные golden.
- Публичная поверхность (`ladix`, `ir`) не тянет `internal/{store,engine,daemon}`/sqlite (`boundary_test.go`).
- Финал: `gofmt`, `go vet ./...` без замечаний, `go test ./...` зелёные, doc-sync `docs/*-model.md`.

## Команды

```sh
go build -o ladix ./cmd/ladix   # из корня
go test ./... && go vet ./...
./ladix run examples/hello.ladix
```

## Контекст основного потока ≤20%

Держать заполнение основного контекста ≤20%. Тяжёлые чтение/поиск/анализ делегировать
субагентам; в основной поток возвращать только выводы, не сырьё. При росте к порогу —
делегируй или сворачивай.
