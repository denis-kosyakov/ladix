# Contract: Встроенные функции дат `сегодня()` / `дата(...)` (активация из deferred)

**Feature**: 004-source-metric | **Источники**: docs/source-metric-model.md §SM-6, §SM-9.C, D-7; docs/stdlib.md «Дата и длительность»; [builtins](../../003-interpreter-eval/contracts/builtins.md) B-3 (deferred-список). Решения **R4** (Clock).

004 активирует из `deferredNames` (`builtins.go:48`) **ровно две** функции: `сегодня` и `дата`. Остальные 10 (`вчера`/`завтра`/`длительность`/`в_секундах`…`в_днях`/3 процессных) **остаются deferred** → `«функция '<имя>' не поддерживается в этой версии»` (§SM-12). Реестр перестаёт быть «23 активных + 12 deferred»: становится **25 активных + 10 deferred = 35**.

## BD-1. Сигнатура `BuiltinFn` (без изменений, [builtins-карта](/tmp/ladix004map/builtins.md) §2)

```go
type BuiltinFn func(i *Interpreter, args []value.Value, pos ast.Position) (value.Value, error)
```

Принимает: `*Interpreter` (для `сегодня` — доступ к `i.clock`, R4), уже **вычисленные** `args`, `pos = CallExpr.Pos()` (для всех ошибок). Конструкторы записей и диспетчер вызова — без изменений:

```go
func fixed(name string, n int, fn BuiltinFn) Builtin       // ArityFixed, проверка N на семпроходе
func overloaded(name string, fn BuiltinFn) Builtin         // ArityOverloaded, проверка арности внутри Fn
```

Конструкторы диагностик (`interpreter.go`): `typeErr → ОшибкаТипа`, `runtimeErr → ОшибкаВыполнения`, `semErr → СемантическаяОшибка`.

## BD-2. `сегодня() → Дата` (фиксированная арность 0)

Регистрация: `add(fixed("сегодня", 0, builtinSegodnya))`. Удалить `"сегодня"` из `deferredNames`.

```go
func builtinSegodnya(i *Interpreter, args []value.Value, pos ast.Position) (value.Value, error)
```

| Аспект | Поведение |
|---|---|
| Арность | ровно 0. `ArityFixed N=0` → лишние аргументы ловит семпроход/защита: `«'сегодня' принимает 0 аргументов, передано M»` (формат §8.3, [runtime-errors](../../003-interpreter-eval/contracts/runtime-errors.md) SEM-ARITY) |
| Результат | `i.clock.Now()` → `value.Дата` (R4, [clock](./clock.md)). **Никогда** `time.Now()` напрямую |
| Детерминизм | фиксирована на запуск (§10.6, CK-4); в тестах = `FixedClock` дата (`2026-05-31`) |

## BD-3. `дата(...) → Дата | Пусто` (перегруженная, §SM-6 дословно)

Регистрация: `add(overloaded("дата", builtinData))` (механизм как `длина`/`диапазон` — арность не проверяется семпроходом, диспетчеризация по `len(args)` и типу **внутри** `Fn`, [builtins-карта](/tmp/ladix004map/builtins.md) §3). Удалить `"дата"` из `deferredNames`.

```go
func builtinData(i *Interpreter, args []value.Value, pos ast.Position) (value.Value, error)
```

| Форма | Поведение |
|---|---|
| `дата(s: Строка)` | разобрать `s` как `YYYY-MM-DD` (BD-4). Успех → `value.Дата{Y, M, D}`. Невалидно (формат/несуществующий календарь) → §SM-9.C `«дата: «<значение>» не является датой»` |
| `дата(п: Пусто)` | → `value.None` (`Пусто`). Ключ к §10.4: запись без поля даты даёт `по_дате: дата(поле) → Пусто` → запись вне окна **без ошибки** |
| `дата(г: Целое, м: Целое, д: Целое)` | собрать дату; невалидный календарь (`м∉1..12`, `д` вне числа дней месяца с учётом високосного) → §SM-9.C `«дата: некорректные год/месяц/день»`. Успех → `value.Дата{Y, M, D}` |

**Диспетчеризация и ошибки арности/типа** (внутри `Fn`):

```
switch len(args) {
case 1:
    switch args[0].(type) {
    case value.Строка: ... парс YYYY-MM-DD ...
    case value.Пусто:  return value.None, nil
    default:           // §SM-9.C: «дата: ожидается Строка или Пусто, получено <тип>»
    }
case 3:
    // все три — value.Целое; иначе §SM-9.C «дата: ожидается …» (тип); невалид календаря → «дата: некорректные год/месяц/день»
default:
    // арность 0, 2, ≥4 → «'дата': неверное число аргументов» (формат перегруженной, [builtins-карта] §5)
}
```

## BD-4. Правила парса `YYYY-MM-DD` (§SM-6, дословно)

- **Ровно 10 символов**, шаблон `\d{4}-\d{2}-\d{2}` (4 цифры, дефис, 2 цифры, дефис, 2 цифры).
- **Валидный календарь:** `M ∈ 1..12`; `D ∈ 1..число_дней(Y, M)`; февраль = 29 в високосный год (григорианское правило: делится на 4, кроме делящихся на 100 без 400).
- **Время/таймзона/`T…` — не в v1** (`SPEC §12`): строка с `T` (например `2026-05-03T00:00:00`) — **невалидна** → `«дата: «<значение>» не является датой»`. Длина ≠ 10, лишние символы, нецифры в позициях цифр — невалидны.
- Парс — собственный (не `time.Parse` со свободным layout): строгая длина 10 и строгий календарь, чтобы `«2026-13-40»`, `«2026-5-3»` (нет паддинга), `«2026/05/03»` отвергались.

## BD-5. Реестр ошибок (§SM-9.C, дословно — без завершающей точки)

```
дата: «<значение>» не является датой           // дата(Строка), формат ≠ YYYY-MM-DD / невалидный календарь
дата: некорректные год/месяц/день               // дата(Целое,Целое,Целое), невалидный календарь
дата: ожидается Строка или Пусто, получено <тип> // дата(x), 1 арг неверного типа
'сегодня' принимает 0 аргументов, передано M     // сегодня(...), лишние аргументы (SEM-ARITY)
'дата': неверное число аргументов                // дата(...) арность 0/2/≥4 (RT-VARIADIC-ARITY)
```

- Гильемы `«…»` — для **дословного строкового значения** (само значение даты); одинарные `'…'` — для имени функции/ключевого слова. `<значение>` = исходная строка-аргумент; `<тип>` = `value.TypeName()`.
- `«<значение>» не является датой` несёт **дословно** переданную строку (например `«2026-13-40»`).
- Категории: `дата: …` (парс/тип/календарь) → `ОшибкаВыполнения`/`ОшибкаТипа` (по §SM-9.C: тип — `ОшибкаТипа`, невалидное значение даты — `ОшибкаВыполнения`); арность `сегодня` (фикс) → `СемантическаяОшибка`; арность `дата` (перегруж.) → `ОшибкаВыполнения`. Позиция всех — `pos = CallExpr.Pos()`.

- `registerBuiltins`: добавить `add(fixed("сегодня", 0, builtinSegodnya))` и `add(overloaded("дата", builtinData))`.
- Инвариант счётчиков `TestBuiltinRegistryClosed` (`builtins_test.go:11-30`): **25 активных + 10 deferred = 35** (было 23/12/35). Обновить вместе с реестром.
- `TestBuiltinDeferredAll` (`builtins_test.go:145-162`) итерирует `deferredNames` — `дата`/`сегодня` из него уходят; добавить позитивные тесты активных `сегодня`/`дата`.
- `docs/stdlib.md` (раздел «Дата и длительность»): `дата`/`сегодня` пометить доступными; `длительность`/`в_*`/`вчера`/`завтра` — `v2 (deferred)`; тексты ошибок `дата` привести к BD-5 дословно.

## BD-7. Границы

- `дата` **не** распознаёт даты-строки автоматически в источниках (JSON-строка остаётся `Строка`, §SM-8.1) — только явный вызов `дата(...)`.
- Арифметика `Дата ± Длительность` / `Дата − Дата` — **не в 004** (нет конструктора `Длительность`, §SM-0); даты сравниваются только `value.Compare` (порядок, §SM-5).
- `сегодня()` не принимает аргументов-смещений (`сегодня(-1)` и т.п.) — это `ArityFixed N=0`.
