# Contract: Инъекция времени `Clock` (детерминизм метрик)

**Feature**: 004-source-metric | **Источники**: docs/source-metric-model.md §SM-7, D-7, D-9; spec.md FR (ось времени); docs/eval-model.md §10.6 (фиксация `сегодня()` на запуск). Решение **R4**.

Единственный канал текущей даты для `eval`/движка метрики. Прямой `time.Now()` в `internal/eval` и движке метрики **ЗАПРЕЩЁН** — точно так же, как вывод идёт только через инъектированный `out io.Writer`, а не `os.Stdout`. Метрика с `период:` считается относительно `сегодня()`; недетерминированное «сегодня» сделало бы golden непроходимым (май ≠ июнь).

## CK-1. Интерфейс

```go
// пакет eval
type Clock interface {
	Now() value.Дата // календарная дата (Year/Month/Day), без времени/таймзоны в v1
}
```

- `Now()` возвращает `value.Дата{Year, Month, Day}` (поля `int`, см. [values](../../003-interpreter-eval/contracts/values.md) C-1.8; репрезентация ISO `YYYY-MM-DD` готова в `repr.go::isoDate`).
- Без времени/таймзоны — v1 (`SPEC §12`). Усечение `time.Time → Y/M/D` делает реализация `Clock`, не вызывающий код.

## CK-2. Реализации

| Реализация | Назначение | Поведение |
|---|---|---|
| `SystemClock{}` | прод (`ladix run`/`ladix metric`) | `Now()` = `time.Now()` в `time.Local`, усечённый до `Y/M/D` → `value.Дата{Year, int(Month), Day}` |
| `FixedClock{D value.Дата}` | тесты | `Now()` = `D` дословно; golden-дата `value.Дата{2026, 5, 31}` (§SM-10) |

```go
type SystemClock struct{}
func (SystemClock) Now() value.Дата {
	t := time.Now() // ЕДИНСТВЕННЫЙ легальный вызов time.Now() — внутри реализации Clock
	return value.Дата{Year: t.Year(), Month: int(t.Month()), Day: t.Day()}
}

type FixedClock struct{ D value.Дата }
func (c FixedClock) Now() value.Дата { return c.D }
```

> **Локаль времени.** Прод-«сегодня» = календарная дата `time.Now()` в `time.Local` (зона сервера). Таймзоны/`ДатаВремя` — v2 (`SPEC §12`, §SM-12).

## CK-3. Инъекция в интерпретатор (R4)

Существующая сигнатура — **два** параметра ([eval-core](/tmp/ladix004map/eval-core.md) §1, `interpreter.go:28`):

```go
func NewInterpreter(out io.Writer, maxDepth int) *Interpreter            // 003 (до 004)
```

004 расширяет **третьим** параметром `clock`:

```go
func NewInterpreter(out io.Writer, maxDepth int, clock Clock) *Interpreter // 004
```

- Новое поле `clock Clock` на структуре `Interpreter` (рядом с `out io.Writer`); инициализируется в литерале `NewInterpreter`.
- Билтины получают `*Interpreter` первым аргументом (`b.Fn(i, args, c.Pos())`, [builtins](#) §SM-6) → `сегодня()` читает `i.clock.Now()` без отдельного протаскивания.
- `сегодня()` и вычисление окна периода в движке метрики (§SM-8.2) читают текущую дату **только** через `i.clock` (или `Clock` движка). Никакой иной путь не зовёт `time.Now()`.

## CK-4. Фиксация на запуск (§10.6)

- `сегодня()` фиксируется один раз на запуск: значение `Clock.Now()` снимается в начале и переиспользуется всеми вызовами `сегодня()` и всеми окнами метрик в пределах одного `run`/`metric`/тика `serve`. Реализация — кеш в интерпретаторе либо однократный снимок; контракт: в пределах запуска `сегодня()` инвариантна.
- `ladix run` и `ladix metric` в проде строят `SystemClock{}` и фиксируют дату на вызов.
- Тесты метрик инъектируют `FixedClock{value.Дата{2026, 5, 31}}` (§SM-10) — все golden-значения и краевые кейсы считаются при `D = 2026-05-31`.

## CK-5. Обновление вызывающих (миграция R4)

Расширение сигнатуры `NewInterpreter` ломает всех существующих вызывающих — обновить **синхронно**:

- `cmd/ladix/main.go` (`runFile`, ветвь `metric`): `eval.NewInterpreter(stdout, maxDepth, eval.SystemClock{})`.
- Все eval-тесты, конструирующие `Interpreter` напрямую: добавить третий аргумент `eval.FixedClock{...}` (для детерминизма; дата нерелевантна там, где нет `сегодня()`/метрик — допустим любой фикс).

## CK-6. Запрет (инвариант)

- Ни один путь `internal/eval` и движка метрики **не вызывает** `time.Now()` напрямую — только через `Clock.Now()`. Единственное место `time.Now()` во всей цепочке — тело `SystemClock.Now()` (CK-2).
- Аналогия с уже принятым контрактом вывода: `печать` пишет только в инъектированный `out`, не в `os.Stdout`; время читается только из инъектированного `Clock`, не из `time.Now()`.

## CK-7. Границы

- `Clock` даёт **только** `Дата` (без времени/таймзоны) — арифметика дат окон (§SM-8.2) считается служебной Go-арифметикой `time.Date(...)` UTC и обратно в `Дата`, но это деталь движка, а не контракт `Clock`.
- `Период`-арифметика, `Длительность`, `вчера`/`завтра` — **не** через `Clock` и **не** в 004 (§SM-12).
- `Clock` не хранит состояние между запусками (нет «вчерашнего» кеша) — это чистый источник «сейчас».
