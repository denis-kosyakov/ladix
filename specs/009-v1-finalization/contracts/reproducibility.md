# Контракт приёмки: воспроизводимость (reproducibility)

**Что контрактует.** Поведение командных блоков README и пользовательского
`docs/quickstart.md` при дословном исполнении из **корня** чистого клона. Это НЕ
интерфейс языка — это контракт CLI-сборки/запуска и smoke-замка. Источник: §VF-1,
§VF-7, FR-001..005, FR-012/FR-013, SC-001/SC-002/SC-006.

## Предусловие

- Свежий клон репозитория, рабочее дерево чистое.
- Установлен Go ≥ 1.25 (минимум из `src/go.mod`).
- Текущий каталог — **корень** репозитория.

## Командные блоки → exit 0

| # | Блок (дословно из README) | Ожидание |
|---|---------------------------|----------|
| R1 | `cd src && go build -o ../ladix ./cmd/ladix` | exit 0; в корне появляется бинарник `./ladix` |
| R2 | `./ladix run examples/hello.ladix` | stdout = `Привет, Уклад!`; exit 0 |
| R3 | `cd src && go test ./...` | 10/10 пакетов `ok`; ноль «no test files»; exit 0 |
| R4 | `cd src && go vet ./...` | exit 0, без замечаний |
| R5 | блоки запуска `serve`/`emit`/`metric` (мост `./ladix …` из корня) | exit 0 на каждом |

**ИНВАРИАНТ.** Ни один блок не требует ручного `cd src`, НЕ упомянутого в README.
Ни одной bare-команды `ladix ` (всегда `./ladix`). Ни одной команды сборки/тестов из
корня без `cd src`.

## Smoke-замок (регрессия)

Smoke-скрипт/CI-шаг прогоняет РОВНО блоки README (R1–R5) + шаги `docs/quickstart.md`
из корня и проверяет exit 0 на каждом. Детерминизм: `hello.ladix` пинит golden
`Привет, Уклад!`; build/test детерминированы по природе; если smoke трогает
`выручка.ladix` — пинит ТОЛЬКО exit 0 (вывод дата-зависим, см. `examples-golden.md`),
не stdout.

## Негативные грани (edge, должны оставаться истинными)

| Команда | Ожидаемая ошибка |
|---------|------------------|
| `go build ...` из корня без `cd src` | `go: cannot find main module` (exit 1) |
| `ladix run …` без `./` и не на PATH | `command not found: ladix` (exit 127) |
| клон на Go 1.22–1.24 | не соберётся (директива `go 1.25.0`) — README указывает фактический минимум |

## Критерий «контракт выполнен»

100% блоков R1–R5 и шагов quickstart дают exit 0 из корня чистого клона; smoke-замок
зелёный; путь «метрика + процесс» quickstart проходится без обращения к `*-model.md`.
