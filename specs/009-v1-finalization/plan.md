## Summary

Закрываем подтверждённые разрывы «док↔реальность», «чеклист↔факт» и «витрина↔скоуп» БЕЗ
добавления новой языковой функциональности. Это **конвейер финализации, а не достройки фич**:
ни одна история не вводит новую языковую конструкцию, builtin или семантику. Затрагиваются ТОЛЬКО
документация, витрина примеров и приёмочные (golden/smoke) тесты.

Шесть скоупов (6 US, 20 FR, 8 SC):

- **US1/§VF-1 (P1) — Воспроизводимость README из чистого клона.** `go.mod` лежит в `src/`, но

  командам сборки/проверки/тестов предпослан `cd src`; ОДИН канонический мост — «собрать в корень»
  (`cd src && go build -o ../ladix ./cmd/ladix`), запуск `./ladix` из корня (ради `data/`/`examples/`);
  тесты — `cd src && go test ./...`. Закрепляется smoke-замком блоков README.
- **US2/§VF-4 (P1) — Честная простановка `CHECKLIST.md`.** 0 из 50 пунктов отмечены, хотя 49
  подтверждаются кодом/тестами. Проставляем `[x]` с доказательством файл:строка каждому; пункт
  `hello.lang` закрывается `[x]` со сноской `.lang→.ladix`. Текст пунктов чеклиста не меняется.
- **US3/§VF-5/§VF-6 (P1) — Полнота витрины против скоупа §3.** Добавляем демо событие-триггера,
  расписание-триггера, мультиисточника/мультиметрики, полного цикла процесса и три отдельных негатива

  детерминизм — `FixedClock` + прогон во временной директории; `выручка.ladix` закрывается отдельным run-golden.
- **US4/§VF-7 (P2) — Пользовательский `docs/quickstart.md`.** «Первая метрика и первый процесс за

- **US5/§VF-2/§VF-3 (P2) — Выравнивание доков под код.** «Go 1.22+»→`go 1.25` (`src/go.mod`); снять
  обещание «Найдено K ошибок.» (тест-замок отсутствия НЕ трогать); задокументировать `src/internal/`
