# Data Model — Активация дата/время builtins (008)

Фича не вводит НОВЫХ типов-значений: `Дата` и `Длительность` (и литерал `5мин`) уже существуют в
языке (введены в предыдущих фичах). 008 активирует функции, которые их производят/потребляют.
Канон единиц времени уже определён лексером (`lexer/keywords.go`). Источник истины — SPEC §4
(типы) и `docs/datetime-builtins-model.md §DB-3/§DB-4`.

---

## Сущность: `Дата`

Значение языка Ladix, представляющее календарный день без времени и таймзоны.

| Поле | Тип Go | Смысл |
|---|---|---|
| `Year`  | int | год |
| `Month` | int | месяц (1..12) |
| `Day`   | int | число (1..31, валидное для месяца) |

- Go-представление: `value.Дата{Year, Month, Day}`. `тип(...)` → `"Дата"`.
- **Производится** функциями `вчера()`, `завтра()` (008) и активной `сегодня()` (004).
- **Источник «сегодня»** — ТОЛЬКО инжектируемый `Clock` через `i.now()` (кеш `i.today`), никогда
  `time.Now()` напрямую. При `ResetRunState()` кеш обнуляется, дата переснимается.
- **Сдвиг ±1 день** выполняется внутренней календарной арифметикой Go (`time.AddDate(0,0,±1)` через
  хелперы `eval/window.go`), доступной автору ТОЛЬКО через `вчера`/`завтра`. Корректно переходит
  границу месяца/года/високос.
- **Операторная арифметика дат** (`Дата ± Длит`, `Дата − Дата`) — вне скоупа (v2, §DB-9).

### Правила валидации (Дата)

- `вчера()`/`завтра()` — арность 0; собственных ошибок выполнения НЕТ, кроме нарушения арности
  (передача любого аргумента → `'<имя>' принимает 0 аргументов, передано M`).

## Сущность: `Длительность`

Значение языка Ladix, представляющее количество единиц времени как пару без нормализации.

| Поле | Тип Go | Смысл |
|---|---|---|
| `Amount` | int64 | значение (любое `Целое`: 0, положительное, отрицательное) |
| `Unit`   | string | единица ∈ канон из 6 |

- Go-представление: `value.Длительность{Amount, Unit}`. `тип(...)` → (тип-имя длительности).
- **Канон единиц (6)**: `сек`, `мин`, `час`, `дн`, `нед`, `мес` (`lexer/keywords.go`). Это
  ЕДИНСТВЕННЫЙ допустимый набор для `Unit`.
- **Без нормализации (D-17)**: `1час ≠ 60мин` — значение и единица хранятся «как есть», без
  приведения к общей единице. Равенство по `{Amount, Unit}`: `длительность(5,"мин") == 5мин`
  истинно; `длительность(60,"мин") == длительность(1,"час")` ЛОЖНО (разные единицы).
- **Конструируется** двумя путями: литералом `5мин` (отдельный путь `evalDurationLit`, не 008) или
  функцией `длительность(значение, единица)` (008 — единственный конструктор из значений).
- **Сравнивается** на `==`/`!=` и порядок одной единицы (активно с 006).
- **Переводится в `Целое`** конвертерами `в_*` (008) — кроме `мес`, который без даты-якоря не
  приводится.

### Правила валидации (конструктор `длительность(значение, единица)`)

Проверки СТРОГО по порядку (первая сработавшая определяет ошибку):

1. **Арность** = 2. Иначе → `'длительность' принимает 2 аргументов, передано M` (существующая
   форма реестра; ловится семпроходом и защитно в рантайме).
2. **Типы**: `значение` обязан `Целое`, `единица` обязана `Строка`. Иначе → **ОшибкаТипа**:
   `длительность: ожидается Целое и Строка, получено <тип> и <тип>` — показываются ОБА полученных
   типа (даже если неверен только один). `Дробное` для `значение` (включая `1.0`) — ошибка типа,
   промоушена `Дробное→Целое` НЕТ.
3. **Единица** ∈ {`сек`,`мин`,`час`,`дн`,`нед`,`мес`}. Иначе → **ОшибкаВыполнения**:
   `длительность: неизвестная единица «<единица>»` (гильемы — единица есть пользовательское
   строковое значение).
4. **Значение** — любое `Целое`, включая `0` и отрицательное: конструируется без ошибки.
   Конструктор НЕ дублирует литерал-валидацию «ноль недель» расписания (SCHED-1 живёт в семпроходе,
   иной слой).

Результат — `value.Длительность{Amount: значение, Unit: единица}` без нормализации. Позиция всех
ошибок = `pos` (`CallExpr.Pos()`).

### Правила валидации и алгоритм (конвертеры `в_секундах`/`в_минутах`/`в_часах`/`в_днях`)

Каждый — арность 1, возврат `Целое`. Алгоритм единый:

1. **Арность** = 1. Иначе → `'<имя>' принимает 1 аргументов, передано M`.
2. **Тип**: `d` обязан `Длительность`. Иначе → **ОшибкаТипа**:
   `<имя>: ожидается Длительность, получено <тип>` (`<имя>` = имя вызванной функции).
3. **Месяцы**: если `d.Unit == "мес"` → **ОшибкаВыполнения**:
   `<имя>: месяцы не приводятся без даты-якоря`. (Конвертеры НЕ вызывают `AddDate`.)
4. **Умножение** на множитель единицы: `totalSec, overflow := mulInt64(d.Amount, секунд[d.Unit])`;
   при `overflow` → **ОшибкаВыполнения** `переполнение целого числа` (существующий хелпер/строка,
   новой строки реестра НЕ вводит).
5. **Целочисленное частное** (усечение к нулю, оба знака):
   - `в_секундах` → `totalSec`
   - `в_минутах` → `totalSec / 60`
   - `в_часах`   → `totalSec / 3600`
   - `в_днях`    → `totalSec / 86400`

Позиция всех ошибок = `pos` (`CallExpr.Pos()`).

### Таблица множителей единица → секунды (локальная карта `int64` в `builtins_duration.go`)

| единица | секунд | вывод |
|---|---|---|
| `сек` | 1 | |
| `мин` | 60 | |
| `час` | 3600 | |
| `дн` | 86400 | 24·3600 |
| `нед` | 604800 | 168·3600 = 7·86400 |
| `мес` | — | **не приводится** (ошибка выполнения, см. п.3) |

Числа согласованы с `engine/deadline.go` (хранит как `time.Duration`), но карта секунд для
конвертеров заводится локально (НЕ глобал пакета).

## Связь сущностей и функций

```text
Clock ──i.now()──▶ Дата ◀── вчера() / завтра() / сегодня()
                            (сдвиг ±1 день через time.AddDate; мес/год/високос корректны)

значение:Целое + единица:Строка ──длительность(...)──▶ Длительность{Amount, Unit}
литерал 5мин ─────evalDurationLit─────────────────────▶ Длительность{5, "мин"}
        длительность(5,"мин") == 5мин  (равенство по {Amount, Unit}, без нормализации)

Длительность{Amount, Unit≠"мес"} ──в_секундах/в_минутах/в_часах/в_днях──▶ Целое
                                   (totalSec / делитель, усечение к нулю)
Длительность{Unit=="мес"}        ──в_*──▶ ОшибкаВыполнения «месяцы не приводятся без даты-якоря»
```

## Инвариант реестра (после активации)

`deferredNames` пуст; реестр встроенных функций — **РОВНО 35 активных + 0 deferred = 35**
(D-D, §DB-6). Все 7 функций зарегистрированы как `ArityFixed` (не перегруженные). Ни одно из 7
имён не даёт диагностику «функция '<имя>' не поддерживается в этой версии» (она ретайрнута,
ветка `if b.Deferred` остаётся инертным backstop'ом).
