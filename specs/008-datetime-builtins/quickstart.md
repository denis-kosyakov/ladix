# Quickstart — дата/время builtins (008)

Короткие примеры на Ladix для 7 активируемых функций. Даты предполагают «сегодня = 2026-05-31»
(в тестах — `FixedClock`; в реальном прогоне дату даёт инжектируемый `Clock`).

## 1. Относительные даты — `вчера()` / `завтра()`

```ladix
показать сегодня()      # 2026-05-31
показать вчера()        # 2026-05-30
показать завтра()       # 2026-06-01  — корректный переход через границу месяца
показать тип(вчера())   # "Дата"
```

`вчера`/`завтра` не принимают аргументов (арность 0) и не дают собственных ошибок.

## 2. Конструктор — `длительность(значение, единица)`

```ladix
показать длительность(5, "мин")            # Длительность 5мин
показать длительность(5, "мин") == 5мин    # истина — равенство с литералом
показать длительность(0, "нед")            # Длительность 0нед — без ошибки
показать длительность(-3, "дн")            # Длительность -3дн — без ошибки
```

Единица — из канона {`сек`,`мин`,`час`,`дн`,`нед`,`мес`}. Значение — любое `Целое`.

## 3. Конвертеры — `в_секундах` / `в_минутах` / `в_часах` / `в_днях`

```ladix
показать в_секундах(длительность(2, "мин"))   # 120
показать в_часах(длительность(1, "дн"))        # 24
показать в_днях(длительность(1, "нед"))        # 7
показать в_секундах(длительность(1, "нед"))    # 604800
```

Усечение к нулю при неделимости (целочисленное деление):

```ladix
показать в_минутах(длительность(90, "сек"))    # 1   (90/60 = 1.5 → 1)
показать в_часах(длительность(90, "мин"))      # 1
показать в_днях(длительность(40, "час"))       # 1
показать в_минутах(длительность(-90, "сек"))   # -1  (к нулю и для отрицательных)
```

## 4. Ошибки — что увидит автор

```ladix
длительность(5, "XYZ")
# Ошибка выполнения: длительность: неизвестная единица «XYZ»

длительность(1.5, "час")
# Ошибка типа: длительность: ожидается Целое и Строка, получено Дробное и Строка

в_секундах(длительность(1, "мес"))
# Ошибка выполнения: в_секундах: месяцы не приводятся без даты-якоря

в_секундах(5)
# Ошибка типа: в_секундах: ожидается Длительность, получено Целое

в_секундах()
# 'в_секундах' принимает 1 аргументов, передано 0
```

`мес` — валидная единица для конструктора (`длительность(1,"мес")` строится), но в число без
даты-якоря не переводится: конверсия месяцев даёт ошибку выполнения во всех 4 конвертерах.

## Чего пока НЕТ (v2)

Операторная арифметика отложена: `дата + длительность`, `дата − дата`, `длительность ± длительность`,
`длительность * X` — по-прежнему ошибка типа. Конструктор и конвертеры самодостаточны; арифметику
оператором вводит будущая версия.
