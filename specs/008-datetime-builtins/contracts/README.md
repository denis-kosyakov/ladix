# Контракты публичного API stdlib Ladix — фича 008

Контракт каждой из 7 активируемых встроенных функций: имя, арность, типы аргументов, тип
результата, ошибки (с байт-в-байт строками) и golden-примеры. Это публичный API stdlib —
наблюдаемое поведение для автора Ladix-скрипта. Источник истины: `docs/datetime-builtins-model.md
§DB-1..§DB-5`; реестр строк ошибок — слой eval (`docs/eval-model.md §8.3`).

Сгруппировано по семейству (а не по 7 файлам):

| Файл | Функции | Возврат |
|---|---|---|
| [вчера-завтра.md](вчера-завтра.md) | `вчера()`, `завтра()` | `Дата` |
| [длительность.md](длительность.md) | `длительность(значение, единица)` | `Длительность` |
| [конвертеры.md](конвертеры.md) | `в_секундах(d)`, `в_минутах(d)`, `в_часах(d)`, `в_днях(d)` | `Целое` |

## Общие инварианты контракта

- Все 7 — `ArityFixed` (не перегруженные). Нарушение арности →
  `'<имя>' принимает N аргументов, передано M` (существующая строка реестра; ловится семпроходом
  и защитно в рантайме).
- Позиция любой ошибки = `CallExpr.Pos()` (строка/колонка в рунах, конституция IV).
- `<тип>` в текстах = `TypeName` фактического значения; `<имя>` = имя вызванной функции.
- 4 новые строки ошибок — байт-в-байт, БЕЗ завершающей точки, с гильемами «…» вокруг
  пользовательского строкового значения. Переполнение и арность — существующие строки, новых не
  вводят.
- После активации ни одно из 7 имён НЕ даёт «функция '<имя>' не поддерживается в этой версии».
