# Контракт: `вчера()` / `завтра()`

Относительные даты от «сегодня». Источник истины §DB-2.

## `вчера()`

| Свойство | Значение |
|---|---|
| Арность | 0 (`ArityFixed N=0`) |
| Аргументы | нет |
| Результат | `Дата` = «сегодня» − 1 календарный день |
| Собственные ошибки выполнения | нет |
| Реализация | `timeToDate(dateToTime(i.now()).AddDate(0, 0, -1))` |

## `завтра()`

| Свойство | Значение |
|---|---|
| Арность | 0 (`ArityFixed N=0`) |
| Аргументы | нет |
| Результат | `Дата` = «сегодня» + 1 календарный день |
| Собственные ошибки выполнения | нет |
| Реализация | `timeToDate(dateToTime(i.now()).AddDate(0, 0, +1))` |

## Поведение

- «Сегодня» берётся ТОЛЬКО через `i.now()` (инжектируемый `Clock`, кеш `i.today`), никогда
  `time.Now()` напрямую. При `ResetRunState()` дата переснимается.
- `AddDate(0,0,±1)` корректно переходит границу месяца/года/високос.

## Ошибки

| Условие | Строка | Класс |
|---|---|---|
| Передан любой аргумент | `'вчера' принимает 0 аргументов, передано 1` (соотв. имя/число) | арность (существующая) |

Новых строк ошибок НЕ вводит (FR-006).

## Golden-примеры (`FixedClock{2026,5,31}`)

```text
сегодня()        ⇒ Дата 2026-05-31
вчера()          ⇒ Дата 2026-05-30
завтра()         ⇒ Дата 2026-06-01     # переход через границу месяца
тип(вчера())     ⇒ "Дата"
тип(завтра())    ⇒ "Дата"
```
