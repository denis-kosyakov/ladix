# Контракт: `длительность(значение, единица)`

Единственный конструктор `Длительность` из вычисленных значений. Источник истины §DB-3.

| Свойство | Значение |
|---|---|
| Арность | 2 (`ArityFixed N=2`) |
| Аргумент 1 `значение` | `Целое` (любое: 0, положительное, отрицательное) |
| Аргумент 2 `единица` | `Строка` ∈ {`сек`,`мин`,`час`,`дн`,`нед`,`мес`} |
| Результат | `Длительность{Amount: значение, Unit: единица}` без нормализации |

## Поведение

- Без нормализации (D-17): `1час ≠ 60мин`, хранится как есть.
- Эквивалентность литералу: `длительность(5,"мин") == 5мин` истинно (равенство по `{Amount, Unit}`).
- `Дробное` для `значение` (включая `1.0`) — ошибка типа, промоушена `Дробное→Целое` НЕТ.
- `значение` = 0 и отрицательное — конструируются без ошибки (не дублирует SCHED-1 «ноль недель»).

## Порядок валидации

1. Арность → 2. Иначе — ошибка арности.
2. Типы → `значение:Целое`, `единица:Строка`. Иначе — ОшибкаТипа (показать ОБА типа).
3. Единица ∈ канон из 6. Иначе — ОшибкаВыполнения.

## Ошибки

| Условие | Строка (байт-в-байт) | Класс |
|---|---|---|
| Неверный тип аргумента(ов) | `длительность: ожидается Целое и Строка, получено <тип> и <тип>` | ОшибкаТипа |
| Единица вне канона | `длительность: неизвестная единица «<единица>»` | ОшибкаВыполнения |
| Нарушение арности | `'длительность' принимает 2 аргументов, передано M` | арность (существующая) |

`<тип>` показывает ОБА полученных типа, даже если неверен только один аргумент.

## Golden-примеры

```text
длительность(5, "мин")            ⇒ Длительность{5, "мин"}
длительность(5, "мин") == 5мин    ⇒ истина
длительность(0, "нед")            ⇒ Длительность{0, "нед"}    # без ошибки
длительность(-3, "дн")            ⇒ Длительность{-3, "дн"}    # без ошибки
длительность(1, "мес")            ⇒ Длительность{1, "мес"}    # конструируется; ошибка лишь при в_*

длительность(5, "XYZ")            ⇒ ОшибкаВыполнения: длительность: неизвестная единица «XYZ»
длительность(1.5, "час")          ⇒ ОшибкаТипа: длительность: ожидается Целое и Строка, получено Дробное и Строка
длительность("5", "мин")          ⇒ ОшибкаТипа: длительность: ожидается Целое и Строка, получено Строка и Строка
длительность(5)                   ⇒ 'длительность' принимает 2 аргументов, передано 1
```
