# Контракт: `в_секундах(d)` / `в_минутах(d)` / `в_часах(d)` / `в_днях(d)`

Перевод `Длительность` в число выбранной единицы. Источник истины §DB-4.

| Свойство | Значение |
|---|---|
| Арность | 1 (`ArityFixed N=1`) |
| Аргумент `d` | `Длительность` |
| Результат | `Целое` (целочисленное частное, усечение к нулю) |

## Алгоритм (единый для всех 4)

1. Арность → 1. Иначе — ошибка арности.
2. `d` обязан `Длительность`. Иначе — ОшибкаТипа.
3. Если `d.Unit == "мес"` → ОшибкаВыполнения (не приводится без даты-якоря; `AddDate` НЕ вызывается).
4. `totalSec, overflow := mulInt64(d.Amount, секунд[d.Unit])`; при overflow → ОшибкаВыполнения
   `переполнение целого числа` (существующая строка).
5. Частное (усечение к нулю, оба знака):
   - `в_секундах` → `totalSec`
   - `в_минутах`  → `totalSec / 60`
   - `в_часах`    → `totalSec / 3600`
   - `в_днях`     → `totalSec / 86400`

## Множители единица → секунды

| `сек` | `мин` | `час` | `дн` | `нед` | `мес` |
|---|---|---|---|---|---|
| 1 | 60 | 3600 | 86400 | 604800 | — (ошибка) |

## Ошибки

| Условие | Строка (байт-в-байт) | Класс |
|---|---|---|
| `d` не `Длительность` | `<имя>: ожидается Длительность, получено <тип>` | ОшибкаТипа |
| `d.Unit == "мес"` | `<имя>: месяцы не приводятся без даты-якоря` | ОшибкаВыполнения |
| Переполнение умножения | `переполнение целого числа` | ОшибкаВыполнения (существующая) |
| Нарушение арности | `'<имя>' принимает 1 аргументов, передано M` | арность (существующая) |

`<имя>` = имя вызванной функции (`в_секундах`/`в_минутах`/`в_часах`/`в_днях`).

## Golden-примеры

Тождества:

```text
в_днях(длительность(1, "нед"))      ⇒ 7
в_часах(длительность(1, "дн"))      ⇒ 24
в_секундах(длительность(2, "мин"))  ⇒ 120
```

Матрица `в_секундах` (×множитель):

```text
в_секундах(длительность(1, "сек"))  ⇒ 1
в_секундах(длительность(1, "мин"))  ⇒ 60
в_секундах(длительность(1, "час"))  ⇒ 3600
в_секундах(длительность(1, "дн"))   ⇒ 86400
в_секундах(длительность(1, "нед"))  ⇒ 604800
```

Усечение к нулю (оба знака):

```text
в_минутах(длительность(90, "сек"))   ⇒ 1     # 90/60 = 1.5 → 1
в_часах(длительность(90, "мин"))     ⇒ 1     # 5400/3600 = 1.5 → 1
в_днях(длительность(40, "час"))      ⇒ 1     # 144000/86400 = 1.6… → 1
в_минутах(длительность(-90, "сек"))  ⇒ -1    # к нулю для отрицательных
```

Ошибки:

```text
в_секундах(длительность(1, "мес"))   ⇒ ОшибкаВыполнения: в_секундах: месяцы не приводятся без даты-якоря
в_минутах(длительность(1, "мес"))    ⇒ ОшибкаВыполнения: в_минутах: месяцы не приводятся без даты-якоря
в_секундах(5)                        ⇒ ОшибкаТипа: в_секундах: ожидается Длительность, получено Целое
в_секундах()                         ⇒ 'в_секундах' принимает 1 аргументов, передано 0
```
