- **Контракт вывода (канон §C-5.3, run-форма, без ребра)** — байты с живого бинаря impl-time, ожидаемо:
  ```

  ```
  Правила формата: `<снимок>`/`<порог>` = `value.String` (числа **без** подчёркиваний: `3000000`,
  `300000.0`); `<оп>` = `BinOp.String` (`<`). Форма **одностройчная** (run), НЕ двухстрочный канон §13.

- **Контракт вывода**: метрика-триггер стартует инстанс `p-000001` процесса `эскалация_плана`; под
  `run` старт процесса тихий (D-13) — печатается строка задачи:

  (дедлайн маскируется `maskDeadlines`). Эскалация-триггер `когда задача просрочена` под `run` печатает

  строки/порядок — с живого бинаря impl-time; дата-зависимое маскируется `<DT>`.
