# Контракт: T-LIFECYCLE (W3)

**Якорь**: `docs/v2-finalization-model.md §F-1` (design-note T-LIFECYCLE). Герметичный, **дата-
независимый** замок жизненного цикла процессной половины §2. Файл: `src/cmd/ladix/quickstart_smoke_test.go`
(build-from-README бинарь, прогон из repo-root, temp `--db`).

## Сценарий (CLI-последовательность)
1. **start**: `ladix start examples/контроль_плана.ladix эскалация_плана 2500000 --db <tmp>`
   → создаётся человеческая задача `t-000001` (исполнитель шага `связаться_с_клиентом`).
2. **complete**: `ladix complete examples/контроль_плана.ladix t-000001 --данные '{"итог":"перезвонит"}'
   --db <tmp>`
   → исполняются авто-шаги догона: `зафиксировать_итог` (`присвоить итог = данные.итог`) →
   `уведомить_crm` (`уведомить crm("итог звонка: " + итог)`).

## Контракт вывода
- **CR-1**: в stdout присутствует строка реального эффекта (байт-точно):
  ```
  [уведомление] crm: итог звонка: перезвонит
  ```
- **CR-2**: в stdout присутствует терминальный статус:
  ```
  инстанс p-000001: выполнен
  ```
- **CR-3 (дата-независимость)**: дедлайн в выводе маскируется (`maskDeadlines` → `срок до <DT>`); в
  **наблюдаемой строке эффекта дат нет** → замок не плывёт по календарю (FR-014). Часы можно инжектить
  фиксированными, но эффект-строка от даты не зависит.
- **CR-4 (мутпроба, FR-010)**: смена ключа payload (`итог`→иное) ИЛИ текста эффекта (`"итог звонка: "`)
  → тест краснит.

## Связанный co-land замок (НЕ часть T-LIFECYCLE, верифицируется в W4)
- `TestCompleteClockInjected` (`src/cmd/ladix/clock_unify_test.go:167`) — единственный сосед, кто
  реально ПРОГОНЯЕТ те же догон-авто-шаги (несёт payload `{"итог":"перезвонит"}`,
  `clock_unify_test.go:179`). Остаётся зелёным; при смене имён шагов/ключа payload покраснеет (exit 1)
  → согласованность перепроверить (FR-012).

## Контрактные требования
- **CR-5**: прогон из repo-root, temp `--db` (`t.TempDir()`) — изоляция БД, дерево чистое.
- **CR-6**: `--данные` с полем `итог`-Строкой обязателен (иначе конкатенация `"итог звонка: " + итог`
  падает на `Пусто` шагом `уведомить_crm` — edge-инвариант payload).
