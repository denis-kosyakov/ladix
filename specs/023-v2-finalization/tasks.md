# Tasks: Финализация v2 — золотой сквозной пример §2

**Input**: Design documents from `/specs/023-v2-finalization/`

**Prerequisites**: plan.md (W1–W5 фазы), spec.md (US1–US4), research.md, data-model.md,
contracts/ (example-source / t-gold-metric / t-lifecycle), quickstart.md

**Якорь истины**: `docs/v2-finalization-model.md` §F-1 (импл-слайс + co-land замки) / §F-6 (приёмка
против §2-DoD). При расхождении побеждает якорь.

**Tests**: Эта фича — **финализация без новой функциональности**; её единственный продукт —
расширенный пример + детерминированные тест-замки. Поэтому тест-задачи здесь НЕ опциональный
TDD-оверлей, а **сам импл-слайс** (golden/lifecycle/мутпробы). Прод-логика движка/хранилища/
интерпретатора НЕ меняется (FR-015): дифф строго в `examples/контроль_плана.ladix` + Go-тестах
`src/cmd/ladix/`.

**Organization**: задачи сгруппированы по user-story (US1=W1, US2=W2, US3=W3, US4=W4) + финальная
фаза W5 (гейты) и мутпробы (self-check). Нумерация фаз отражает W1–W5 анкора.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: параллелизуемо (другой файл, нет зависимостей от незавершённых задач)
- **[Story]**: к какой user-story относится (US1=W1, US2=W2, US3=W3, US4=W4)
- Все пути — абсолютные от корня repo (`/Users/denis/dev/ladix`); в описаниях даны relative-от-root.

## Path Conventions

- Single project, Go-модуль в `src/`. Точка инъекции — CLI-слой `src/cmd/ladix/` (тесты) +
  декларативный пример `examples/`.
- RUN-путь: `runFile(path, "", maxDepth, caller, clock, &out, &err)` (`src/cmd/ladix/main.go:227`).
- METRIC-путь: `runMetric(path, metricName, maxDepth, clock, &out, &err)` (`src/cmd/ladix/main.go:300`).
