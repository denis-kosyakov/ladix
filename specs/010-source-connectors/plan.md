## Summary

Фича A1 (срез M1 хартии v2) снимает три ограничения §12 SPEC для источников БЕЗ поломки v1: атрибут
`тип:` (`json`|`csv`|`ndjson`, по умолчанию `json`), блок схемы `поля:` (типизированные поля
`Целое`/`Дробное`/`Строка`/`Логическое`/`Дата`) и распознавание дат (поле `Дата` парсится из строки
ISO `ГГГГ-ММ-ДД` в `value.Дата` тем же строгим `parseISODate`, что и builtin `дата(...)`). Реальная
CSV-выгрузка кормит существующую метрику v1 и даёт тот же скаляр, что эквивалентные JSON/NDJSON.
**Механизм:** чистый фронтенд + загрузчик — аддитивные узлы/атрибуты AST, ключевое слово `KW_TYPE` и
семантические проверки на этапе Analyze, диспетчер `loadJSON`/`loadCSV`/`loadNDJSON` + `applySchema`
(пересборка записей), при нулевых `тип:`/`поля:` поведение побайтно эквивалентно v1 JSON schemaless.
