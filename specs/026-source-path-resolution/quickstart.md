# Quickstart: проверка резолва путей источников (фича 026)

Все команды — из каталога `src/` (там `go.mod`), бинарник собирается в корень репозитория.

## Сборка

```sh
cd src
go build -o ../ladix ./cmd/ladix
cd ..
```

## 1. Запуск примера по относительному пути (file-relative дефолт)

```sh
# Из КОРНЯ репозитория — путь к программе относительный, данные в examples/data/
./ladix run examples/выручка.ladix
# Ожидаемо: метрика вычислена (источник examples/data/sales.json найден), exit 0
```

## 2. Запуск из ПОСТОРОННЕГО каталога по абсолютному пути (ключевой сценарий US1)

```sh
cd /tmp
/путь/к/репо/ladix run /путь/к/репо/examples/выручка.ladix
# Ожидаемо: exit 0 — источник найден относительно каталога программы (examples/),
# а НЕ относительно /tmp. Это и есть переносимость артефакта.
```

## 3. Переопределение базы флагом `--source-base` (US2)

```sh
# Скопировать данные в отдельный каталог и резолвить оттуда:
mkdir -p /tmp/altdata/data && cp examples/data/sales.json /tmp/altdata/data/
./ladix run examples/выручка.ladix --source-base /tmp/altdata
# Ожидаемо: exit 0 — источник прочитан из /tmp/altdata/data/sales.json

# Форма со знаком равенства — идентично:
./ladix run examples/выручка.ladix --source-base=/tmp/altdata
```

## 4. Пропуск значения флага → exit 2 (US2 сценарий 3)

```sh
./ladix run examples/выручка.ladix --source-base
echo "exit=$?"
# Ожидаемо: stderr «ladix: флаг --source-base требует значение», exit=2
```

## 5. Диагностика: несуществующий файл показывает резолвленный путь (US3)

```sh
# Запустить из каталога БЕЗ нужных данных и без правильной базы:
cd /tmp
/путь/к/репо/ladix run /путь/к/репо/examples/выручка.ladix --source-base /tmp/nope
echo "exit=$?"
# Ожидаемо: ошибка «источник 'продажи': файл «/tmp/nope/data/sales.json» не найдено»
# — в тексте виден ИТОГОВЫЙ (резолвленный) путь.
```

## 6. Регресс: вывод не изменился, тесты зелёные

```sh
cd src
go build ./...
go vet ./...
go test ./...
# Ожидаемо: всё зелёное; golden-байты stdout примеров не изменились.
```

## Чек-лист приёмки

- [ ] `examples/выручка.ladix` (и прочие примеры с источниками) запускаются по абсолютному пути из
      произвольного cwd → exit 0.
- [ ] `--source-base <dir>` и `--source-base=<dir>` работают во всех 5 подкомандах
      (run/serve/start/complete/metric).
- [ ] Пропуск значения `--source-base` → exit 2 + RU-сообщение.
- [ ] Абсолютный путь источника читается как есть независимо от базы.
- [ ] Ошибка «файл не найден» содержит резолвленный путь.
- [ ] `go build/vet/test ./...` зелёные; stdout-байты примеров неизменны.
- [ ] В доках нет «cwd-relative» / «из корня репо» / «отложен в v2» про пути источников.
