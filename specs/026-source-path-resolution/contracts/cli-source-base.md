# Контракт: CLI-флаг `--source-base` и резолвер путей источников

## CLI-флаг `--source-base`

**Применимость**: подкоманды, грузящие источники — `run`, `serve`, `start`, `complete`, `metric`
(5 из 5). В подкомандах, не грузящих источники, флаг не вводится.

**Формы записи** (зеркало `--db`/`--interval`):

| Ввод | Результат |
|------|-----------|
| `--source-base <dir>` | базовый каталог = `<dir>` |
| `--source-base=<dir>` | базовый каталог = `<dir>` (идентично) |
| (флаг отсутствует) | базовый каталог = `filepath.Dir(<путь .ladix-файла>)` |
| `--source-base` без следующего аргумента (или за ним другой `--flag`) | stderr `ladix: флаг --source-base требует значение`; **exit 2**; программа не выполняется |

**Приоритет**: `--source-base` > каталог программы. Значение трактуется как каталог (может быть
относительным или абсолютным).

**Коды выхода**: совпадают с существующими CLI-usage-ошибками — `2` для ошибки использования.

## Резолвер `resolveSourcePath` (eval)

**Сигнатура**: `func (i *Interpreter) resolveSourcePath(p string) string`

**Контракт**:

| Вход `p` | `sourceBase` | Выход |
|----------|--------------|-------|
| абсолютный (`filepath.IsAbs`) | любой | `p` (как есть) |
| относительный | `"base/dir"` | `filepath.Join("base/dir", p)` |
| относительный | `""` (дефолт) | `p` (≡ cwd-relative) |
| относительный | `"."` (программа в cwd) | `p` (≡ cwd-relative) |

**Инварианты**:
- Чистая функция: без I/O, без мутаций, детерминирована.
- Результат — путь, передаваемый в `os.Open` и в текст ошибки «файл не найден».
- Применяется единообразно во всех трёх загрузчиках (JSON/CSV/NDJSON).

## Контракт ошибки «файл источника не найден» (не меняется по форме)

- Текст: `источник '<имя>': файл «<резолвленный-путь>» не найден`.
- Категория/тип: `errors.ОшибкаВыполнения` (через `runtimeErr`).
- Позиция: `decl.Pos()` (строка/колонка объявления источника).
- **Изменение**: `<резолвленный-путь>` теперь = `resolveSourcePath(decl.File.Value)` вместо сырого
  `decl.File.Value`. Шаблон текста и код ошибки — без изменений (FR-008).

## Инвариант неизменности (регресс-барьеры)

- `NewInterpreter(out, maxDepth, clock)` — сигнатура цела (37 call-sites не трогаются).
- `store.Store` — 18 методов целы; `internal/{store,engine,daemon}` — пустой дифф.
- `stdout`-байты существующих примеров/сценариев — без изменений (SC-003).
- 0 новых внешних зависимостей; 0 новых ключевых слов/builtins/eval-кодов.
