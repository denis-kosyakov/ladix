# Data Model: Разрешение путей источников

Фича не вводит новых durable-сущностей (Store не затрагивается). Единственная новая концепция —
рантайм-состояние «базовый каталог источников» на интерпретаторе.

## Сущность: Базовый каталог источников (`sourceBase`)

- **Где живёт**: поле `sourceBase string` на `eval.Interpreter` (рантайм-состояние процесса, не
  durable, не сериализуется).
- **Семантика**: каталог, относительно которого разрешаются **относительные** пути к файлам данных
  источников. Абсолютные пути базу игнорируют.
- **Инициализация**: пусто (`""`) при `NewInterpreter`. Дефолт `""` означает «резолв относительно
  cwd процесса» (`filepath.Join("", rel) == rel`) — сохраняет старое поведение для кода, не
  задающего базу (большинство юнит-тестов eval).
- **Установка**: сеттер `SetSourceBase(dir string)` (зеркало `SetProcessRuntime`). Вызывается CLI
  один раз после построения интерпретатора.
- **Приоритет источника значения** (вычисляется в CLI, не в eval):
  1. `--source-base <dir>` (если задан) — высший приоритет.
  2. иначе `filepath.Dir(<путь .ladix-файла>)` — каталог программы.
- **Жизненный цикл в `serve`**: устанавливается один раз при сборке демона; `ResetRunState` на
  каждом тике сбрасывает `today` и `recordCache`, но **не** `sourceBase` → база стабильна между
  тиками, источники перечитываются по тому же резолву (FR-009).

## Правило разрешения (`resolveSourcePath`)

```
resolveSourcePath(p):
    если filepath.IsAbs(p):  вернуть p            # D-2: абсолютный — как есть
    иначе:                   вернуть filepath.Join(sourceBase, p)   # D-1: file-relative
```

- Идемпотентно по форме (чистая строковая функция, без I/O).
- Результат подставляется в `os.Open` и в текст ошибки «файл не найден» (FR-008: диагностируется
  итоговый путь).

## Затрагиваемые существующие сущности (без изменения контракта)

| Сущность | Изменение | Контракт |
|----------|-----------|----------|
| `ast.SourceDecl.File` | не меняется (значение пути читается как есть) | цел |
| `eval.Interpreter` | +поле `sourceBase`, +метод `SetSourceBase`, +метод `resolveSourcePath` | `NewInterpreter` сигнатура цела |
| `store.Store` | не затрагивается | 18 методов целы |
| `engine.ProcessRuntime` | не затрагивается | сигнатуры целы |
