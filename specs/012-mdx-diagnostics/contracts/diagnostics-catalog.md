## C-CAT-2 — неприкосновенные инварианты формата
- Двухстрочный канон «Ошибка в строке N, колонка M:»⏎«<текст>» — без изменений (FR-011).
- Позиция (строка+колонка, с 1, в рунах) — у 100% диагностик.
- Коды (`L-*`/`SE-*`) наружу НЕ выводятся.
- Псевдо-лексемы (`конец строки`/`увеличение отступа`/`конец блока`/`конец файла`) — без изменений.
- Наружу не течёт «токен»/«литерал» в scope A (проверка-замок: stderr/golden scope A не содержит этих слов).
