# Contracts — M-DX «Диагностика и восстановление парсера»

Поведенческие контракты вехи. Не код — проверяемые инварианты, материализуемые golden-/инвентарь-тестами.

- [`parser-recovery.md`](./parser-recovery.md) — DX1: подавление фантомного каскада (C-REC-1..6). Кейсы счётчиков диагностик (1/1/2), границы анти-over-suppress, мутант-доказательство, decl-сайты по мутпробе.
- [`diagnostics-catalog.md`](./diagnostics-catalog.md) — DX2: переформулировка scope A (C-CAT-1), неприкосновенный формат (C-CAT-2), ссылочные категории байт-в-байт (C-CAT-3), полнота с count-locks (C-CAT-4), подсказки (C-CAT-5), витрина (C-CAT-6).

Канон новых формулировок — `docs/diagnostics-model.md` (создаётся в implement). Перенос в большой `SPEC §13.4` — зона архитектора на шве.
