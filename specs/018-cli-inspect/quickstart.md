# Quickstart — B6 `ladix inspect` (демо-пара B5→B6)

Цель: показать, что после `ladix start` (B5) инстанс виден через `ladix inspect` (B6) в ОДНОЙ `--db`.

## Предусловие

Сборка из `src/`: `go build -o ladix ./cmd/ladix` (или `go run ./cmd/ladix …`). Фикстура `.ladix` с
процессом `эскалация_плана(факт)`, у которого первый шаг человеческий, со `срок:` и `исполнитель:`
(как §AU-12.B / витрина M2). Детерминизм времени в golden — `<время>` маскируется.

## Шаги

```sh
# 1) Создать инстанс в общей БД (B5). Дефолт --db = ladix.db; здесь явно demo.db.
ladix start demo.ladix эскалация_плана 2500000 --db demo.db
# stdout:
#   [задача] t-000001 → менеджер, шаг 'связаться_с_клиентом', срок до <время>
#   запущен инстанс p-000001

# 2) Посмотреть снимок инстанса (B6) — та же БД.
ladix inspect p-000001 --db demo.db
# stdout:
#   инстанс p-000001: процесс эскалация_плана, статус ожидает, шаг 'связаться_с_клиентом'
#   переменные:
#     факт = 2500000
#   задачи:
#     t-000001 шаг 'связаться_с_клиентом' → менеджер, срок до <время>, открыта

# 3) Неизвестный инстанс → дословная CLI-ошибка, exit 2.
ladix inspect p-999999 --db demo.db
# stderr: ladix: инстанс 'p-999999' не найден
# echo $? → 2
```

## Что демонстрируется

- **Единая `--db`** (D-AU-10): `start` и `inspect` указывают на один `demo.db`; без `--db` оба дефолтят
  в `ladix.db` (семья complete/tasks/emit). MemoryStore эфемерен → не годится для пары.
- **Read-only снимок**: `inspect` читает Store напрямую (`LoadInstance` + `ListTasksByInstance`), БЕЗ
  движка; Store не мутируется.
- **Лёгкая история**: после `complete`/`serve` (закрытие/эскалация задачи) повторный `inspect` покажет
  `, завершена` / `, эскалирована` соответственно (открытые + завершённые в одном списке, ID ASC).

## Проверка эскалации (после serve, опционально)

```sh
# serve эскалирует просроченную задачу (B4, durable Escalated). Затем:
ladix inspect p-000001 --db demo.db
# строка задачи: t-000001 шаг '…' → менеджер, срок до <время>, открыта, эскалирована
```

## Связь с гейтом

Полная end-to-end сборка §AU-12.B/§AU-12.C (`start`→`serve`→`complete`→`inspect`) собирается на
M2-гейте, НЕ в этой фиче. Здесь — исполнимость пары `start`→`inspect` и дословный канон вывода.
