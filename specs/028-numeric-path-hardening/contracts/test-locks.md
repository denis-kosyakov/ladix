### Заметки к конструкциям

- **Непустое окно** (paid+ежемесячно) обязательно для A1/A2/A4/A5: иначе D4-1
  (metric_engine.go:79-81) короткозамкнёт корневой дериватив в `Пусто` ДО `combine*`.
- **A3/A4 требуют кастом-фикстуры** (поле `-9223372036854775808` для MinInt64; поле `1e300`
  для конечного большого float). Записать через `writeJSON(t, t.TempDir(), …)` и подставить
  путь в `SourceDecl.File.Value` (как `buildMetricInterp` делает с `salesPath()`), либо
  построить `SourceDecl`/`MetricDecl` напрямую и вызвать `evalMetric`.
- **A7 целое-без-точки** (`99999999999999999999`): эмпирически `Float64()` даёт **конечный
  `1e20`**, НЕ `±Inf` — поэтому ассерт «→ Дробное» (число не None), а гарантированный `±Inf`
  даёт только `1e400`/`-1e400`. Существующий `TestPayloadToRecordValueTypes` уже пинит
  «big→Дробное»; A7 ДОБАВЛЯЕТ `1e400`/`-1e400`→`±Inf` (ранее не покрыто).
- **NaN/Inf — только `math.IsNaN`/`math.IsInf`**, никогда `==` (NaN != NaN).
