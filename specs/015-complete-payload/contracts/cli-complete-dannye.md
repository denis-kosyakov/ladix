# Contract: CLI-флаг `--данные` команды `complete`

Слой: `cmd/ladix/main.go` (`completeMain` :333, `completeTask` :402).

## C-CLI-1 — грамматика

```text
ladix complete <файл> <id> [--db путь] [--данные '{…}'] [--вебхук URL] [--max-depth N]
```

- Флаг `--данные` опционален; формы `--данные V` и `--данные=V` (зеркало `--вебхук`).
- Значение — строка JSON-объекта.

## C-CLI-2 — парсинг (в `completeMain`)

- `--данные V`: если значения нет (флаг последний) → stderr
  `ladix: флаг --данные требует значение`, **exit 2**.
- `--данные=V`: `V` = всё после `=`.
- Захваченное сырое значение `payloadRaw` передаётся в `completeTask` (декод там).
- Без флага → `payloadRaw == ""` (пустая строка).

## C-CLI-3 — декод + валидация (в `completeTask`, ПЕРЕД `eng.Complete`)

```text
data, err := jsonval.PayloadToRecord(payloadRaw)
if err != nil {
    fmt.Fprintf(stderr, "ladix: неверный JSON в --данные: %s\n", err)  // деталь = err
    return 2
}
... eng.Complete(taskID, data) ...
```

- Пустая строка → `PayloadToRecord` возвращает пустую `Запись`, **без ошибки**
  (поведение jsonval) → `data` пуста, путь штатный.
- Невалидный JSON / не-объект / массив → ошибка → дословно
  **`ladix: неверный JSON в --данные: <деталь>`**, **exit 2**, ДО `eng.Complete`
  (Store НЕ тронут).
- Декод — на CLI (корень композиции, импорт `jsonval` допустим); движок получает
  `value.Запись`.

## C-CLI-4 — точный текст ошибки (§AU-10.C, дословно)

```
ladix: неверный JSON в --данные: <деталь>
```

stderr, exit 2. Префикс `ladix: неверный JSON в --данные: ` — дословно, НЕ
переформулировать (Принцип VIII). `<деталь>` — текст error от `PayloadToRecord`.

## Инварианты (замки)

| Инвариант | Тест | Мутация → красный |
|-----------|------|-------------------|
| Без флага → пусто, не ошибка | complete без `--данные` | golden/exit идентичен доB3 |
| `--данные` без значения | `complete f t --данные` | `ladix: флаг --данные требует значение` exit 2 |
| Плохой JSON дословно | `--данные '{не'` | строка ≠ канон или exit ≠ 2 → красный |
| Не-объект отвергнут | `--данные '[1,2]'` | `ladix: неверный JSON в --данные: …` exit 2 |
| Валидация ДО мутаций | плохой JSON, затем читать Store | инстанс/задача без изменений |
