# Quickstart: проверка B1 (захват результата `вызвать`)

Команды из корня репозитория. Сборка/тесты — из `src/` (go.mod там). Сборка — для L1-Реализации; на фазе спецификации бинарника ещё нет.

## Сборка
```bash
cd src && go build -o ../ladix ./cmd/ladix && cd ..
```

## B1 — захват результата в переменную (ручная проверка)

Под дефолт-стабом движка результат `вызвать`-выражения = `Пусто` (`value.None`), печатается прежняя строка `[вызов] …`.

```bash
cat > /tmp/b1.ladix <<'EOF'
процесс демо():
    шаг проверка:
        присвоить ответ = вызвать crm("клиент")
        печать(ответ)
EOF
./ladix run /tmp/b1.ladix; echo "exit=$?"
# ожидаем: строку стаба «[вызов] crm(клиент)» и печать «Пусто»; exit 0
```

## B1 — statement-форма `вызвать` по-прежнему работает (развязка контекста)
```bash
printf 'процесс д():\n    шаг с:\n        вызвать ИТ("заявка")\n' > /tmp/b1s.ladix
./ladix run /tmp/b1s.ladix; echo "exit=$?"
# ожидаем: «[вызов] ИТ(заявка)» (CallAction, путь v1); exit 0
```

## B1 — `вызвать` как аргумент / элемент списка
```bash
printf 'процесс д():\n    шаг с:\n        печать(вызвать сервис())\n' > /tmp/b1a.ladix
./ladix run /tmp/b1a.ladix; echo "exit=$?"   # вызвать допустим как аргумент
```

## Инвариант — `уведомить` остаётся только statement
```bash
printf 'процесс д():\n    шаг с:\n        присвоить x = уведомить кто("a")\n' > /tmp/b1n.ladix
./ladix run /tmp/b1n.ladix; echo "exit=$?"
# ожидаем: синтаксическую ошибку (уведомить не выражение), exit 1 — как в v1
```

## Инвариант — golden §EN-7 печать-стаба цел
```bash
cd src
go test ./internal/engine/... -run EN7 -count=1    # печать [вызов]/[уведомление] байт-в-байт
go test ./... -count=1                              # полный гейт
cd ..
```

## Критерии приёмки (срез spec SC-001..007)
- `присвоить r = вызвать сервис(x)` → `r == Пусто` под стабом, без ошибки (SC-001).
- `ProcessRuntime` = 8 методов; `var _ eval.ProcessRuntime` компилируется (SC-002).
- `eval` не импортирует `store`/`engine` (SC-003): `cd src && ! go list -deps ./internal/eval | grep -E 'internal/(store|engine)$'`.
- Существующие golden §EN-7 и v1-parser-тесты зелёные, тексты не изменены (SC-004/005).
- `вызвать`-выражение в RHS/аргументе/списке; `вызвать` отдельной строкой → действие; `уведомить` в выражении → ошибка (SC-006).
- 0 новых зависимостей; пустой дифф `store`/драйвера (SC-007).
