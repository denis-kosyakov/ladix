## Форматы печать-стаба (байт-точно, §AU-4.2 / §EN-7)

```
[вызов] <имя>(<арг1, арг2, …>)          // вызвать; разделитель ", "; без аргументов "[вызов] <имя>()"
[уведомление] <получатель>: <арг1 арг2 …>  // уведомить с ≥1 аргументом; разделитель " "
[уведомление] <получатель>                 // уведомить без аргументов (без двоеточия и хвостовых пробелов)
```

`<арг>` = `value.String(аргумент)` (тот же `repr`; Длительность → `3дн`). Каждая строка завершается `\n`.
