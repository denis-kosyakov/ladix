# Contract: CLI-проводка `--вебхук` / `LADIX_WEBHOOK`

**Feature**: 014-real-effects | **Граница**: `cmd/ladix` | **Источник**: §AU-4.5 / §AU-9 / §AU-10.C

## Команды и активация

| Команда | `--вебхук` | env `LADIX_WEBHOOK` | прим. |
|---|---|---|---|
| `run` | ✅ | ✅ | дефолт MemoryStore |
| `serve` | ✅ (ТОТ ЖЕ движок) | ✅ | догон дедлайнов + триггеры |
| `complete` | ✅ | ✅ | эффекты на догоне |
| `start` (B5) | ✅ | ✅ | co-land с B5, если ещё не поставлена |
| `metric`/`tasks`/`emit` | ❌ | ❌ | без вебхука |

## Семантика проводки

1. URL = `--вебхук`, иначе env `LADIX_WEBHOOK`, иначе пусто.
2. Пусто → движок строится БЕЗ `WithExternalCaller` → дефолт-стаб `printCaller`.
3. Валидный URL → `NewEngine(..., WithExternalCaller(webhookCaller{baseURL, &http.Client{Timeout:…}}))`.
4. Невалидный URL → CLI-ошибка, движок НЕ строится.

## CLI-ошибка (ДОСЛОВНО, §AU-10.C / §EN-8.B)

```
ladix: неверный URL вебхука '<URL>'
```

- Поток: **stderr**. Код выхода: **2**. stdout пуст.
- Идёт штатным CLI-каналом (как `ladix: неверный JSON в --данные: …`); позиции нет (корень композиции).

## Контрактные обязательства

| # | Обязательство | Проверка |
|---|---|---|
| L-1 | `run --вебхук <httptest>` → POST на URL (стаб НЕ печатается) | httptest получает POST; stdout без `[вызов]` |
| L-2 | env `LADIX_WEBHOOK=<httptest>` без флага → POST на URL | httptest получает POST |
| L-3 | `--вебхук` приоритетнее env при обоих заданных | POST на флаг-URL, не env-URL |
| L-4 | `--вебхук '<невалид>'` → stderr ровно `ladix: неверный URL вебхука '<невалид>'`, exit 2, stdout пуст | golden exact-match + код выхода |
| L-5 | `serve --вебхук <httptest>` → эскалация дедлайна POST на тот же URL | httptest получает POST из догона |
| L-6 | любая команда без флага/env → дефолт-стаб, §EN-7 байт-точно | golden §EN-7 цел |

## Инверсные мутпробы

- L-4: текст ошибки изменён (напр. «неправильный URL» / без кавычек / в stdout / exit 1) → exact-match golden КРАСНЕЕТ.
- L-4: невалидный URL пропускается без валидации → движок строится с битым `webhookCaller` → нет ошибки → L-4 КРАСНЕЕТ.
- L-1/L-2: env не читается (только флаг) → L-2 КРАСНЕЕТ (POST не уходит).
- L-5: `serve` строит ОТДЕЛЬНЫЙ движок для догона без вебхука → эскалация печатает стаб → L-5 КРАСНЕЕТ (httptest не получил POST).
- L-3: env читается поверх флага → L-3 КРАСНЕЕТ (POST на env-URL).

## Границы

- env читается в корне композиции, передаётся параметром (Принцип V).
- Валидация URL — до запуска движка; невалидный → движок не строится, программа не исполняется.
- `start`-проводка co-land с подфичей B5 (зависимость, не дублировать команду).
