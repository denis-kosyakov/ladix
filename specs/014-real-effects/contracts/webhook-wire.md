# Contract: Провод HTTP (`webhookCaller` + `internal/jsonval`)

**Feature**: 014-real-effects | **Граница**: `internal/engine`, `internal/jsonval` | **Источник**: §AU-4.3 / §AU-5.2

## Тело запроса (value → plain-JSON)

```
POST <baseURL>
Content-Type: application/json

{"цель": <target>, "данные": [<args как plain-JSON>]}
```

Энкодер НОВЫЙ (нетегированный), `internal/jsonval.EncodeBody`:

| `value` тип | plain-JSON |
|---|---|
| `Целое`/`Дробное` | число |
| `Строка` | quoted |
| `Булево` | `true`/`false` |
| `Пусто` | `null` |
| `Список` | array |
| `Запись` | object (ключи в порядке появления) |
| `Дата`/`Длительность`/`Период` | строковая форма (решение impl, задокументировать) |

## Декод ответа (`Call`)

- Тело ответа → `jsonval.DecodeValue`: JSON-объект → `Запись`, скаляр → `Value`.
- **ПУСТОЕ тело → `Пусто` (`value.None`)**, проверка ДО `DecodeValue` (декодер на пустом потоке вернёт ошибку).
- `Notify` ответ игнорирует (best-effort).

## Контрактные обязательства

| # | Обязательство | Проверка (httptest) |
|---|---|---|
| W-1 | `вызвать crm(клиент)` → POST на `baseURL`, `Content-Type: application/json`, тело `{"цель":"crm","данные":["клиент"]}` | сервер фиксирует метод/URL/заголовок/тело |
| W-2 | `уведомить ИТ: x` → POST тело `{"цель":"ИТ","данные":["x"]}`, ответ игнорируется | то же |
| W-3 | ответ-объект `{"статус":"ок"}` → `Call` вернул `Запись{статус:"ок"}` | присвоить + проверка значения |
| W-4 | пустое тело ответа → `Call` вернул `Пусто` (`value.None`) | присвоить + проверка `value.None` |
| W-5 | каждый тип `value` сериализуется в plain-JSON БЕЗ обёртки `{"т","зн"}` | unit-тест энкодера по таблице типов |
| W-6 | `DecodeValue`/`PayloadToRecord` лифтнуты в `jsonval`; `daemon` импортирует `jsonval` | перенос `TestPayloadToRecordValueTypes`; импорт-граф |
| W-7 | `jsonval` импортирует только `value`+stdlib (листовой-совместим) | импорт-граф; НЕ из `eval` |
| W-8 | реальный POST — только под `net/http/httptest`; конечный `httpClient.Timeout` | тест без живой сети |

## Инверсные мутпробы

- W-1: `webhookCaller` не шлёт POST (или шлёт GET / не на baseURL / без Content-Type) → httptest-замок КРАСНЕЕТ (сервер не получил ожидаемое).
- W-1: тело тегированное `{"т":"Строка","зн":"клиент"}` (через `store/codec.encodeValue`) → W-1/W-5 КРАСНЕЕТ (форма тела не та).
- W-4: пустое тело идёт прямо в `DecodeValue` (без guard) → возвращает ошибку вместо `Пусто` → W-4 КРАСНЕЕТ.
- W-3: ответ декодируется через `PayloadToRecord` (требует объект) на скаляре → паника/ошибка на скалярном ответе → красная ветка.
- W-5: энкодер `Запись` теряет порядок ключей → детерминизм-замок КРАСНЕЕТ.

## Границы

- `webhookCaller` — единственный потребитель сети; изолирован за `ExternalCaller`.
- Второй декодер источников M1 (`eval/source_loader.go`) НЕ сливается с `jsonval` (другая семантика overflow/дат).
