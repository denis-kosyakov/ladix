# Contract: Каталог лексических ошибок (дословный)

**Feature**: 001-lexer-tokens | **Источники**: SPEC §13 (§13.4), docs/grammar.md §10.1, spec.md US2/FR-024

Тексты воспроизводятся **ДОСЛОВНО** (конституция VIII, FR-024). Переформулировать ЗАПРЕЩЕНО. Каждый
текст идёт под заголовком канонического двухстрочного формата (SPEC §13):

```
Ошибка в строке N, колонка M:
<описание>
```

`<описание>` ниже — это `LexError.Msg` (без заголовка). `N`/`M` — 1-based, колонка в **рунах**.
В текстах с подстановкой реальный символ/лексема вставляется внутрь одинарных кавычек как есть.

## Каталог (11 канонических текстов — SC-004)

| # | Категория случая | `Msg` (дословно) | Позиция (колонка) | Источник |
|---|---|---|---|---|
| **L-1** | таб в ведущих пробелах | `табы в отступах запрещены, используйте пробелы` | позиция таба | §13.4, FR-020, US2.1 |
| **L-2** | таб между токенами / внутри строки | `табы запрещены, используйте пробелы` | позиция таба | D3/FR-020 |
| **L-3** | отступ не кратен 4 | `отступ должен быть кратен 4 пробелам` | колонка 1 / отступа | FR-021, US2.2 |
| **L-4** | возврат на отсутствующий уровень | `отступ не соответствует ни одному внешнему уровню` | колонка 1 | grammar §10.1, US2.3 |
| **L-5** | незакрытая строка (до EOF) | `незакрытый строковый литерал` | открывающая кавычка | FR-018, US2.4 |
| **L-6** | перевод строки внутри строки | `незакрытый строковый литерал (перевод строки внутри строки запрещён)` | открывающая кавычка | FR-018, US2.4 |
| **L-7** | неизвестный escape | `неизвестная escape-последовательность '\q'` | позиция `\` | FR-018, US2.5 |
| **L-8** | неверный числовой литерал (форма) | `неверный числовой литерал '1__000'` | первая руна числа | FR-015/FR-016, US2.6 |
| **L-9** | неизвестный суффикс длительности | `'5XYZ' — неизвестный суффикс длительности. Допустимые: сек, мин, час, дн, нед, мес.` | первая руна run | §13.4, FR-017, US2.7 |

## Правила подстановки (для текстов с `'…'`)

| # | Что подставляется | Примеры |
|---|---|---|
| L-7 | реальная escape-последовательность `\X` целиком | `'\q'`, `'\x'` |
| L-8 | реальная битая лексема числа целиком | `'1__000'`, `'5_'`, `'100_'` |
| L-9 | реальный прочитанный run **целиком** (без частичного `5дн`+`ей`) | `'5XYZ'`, `'3лет'` |
| L-10 | реальный неожиданный символ (в т.ч. одиночный `!`) | `'@'`, `'!'` |
| L-11 | реальное зарезервированное слово | `'параллельно'`, `'модуль'`, `'тип'` |

## Семантические замечания

- **L-1 vs L-2** — два РАЗНЫХ текста (D3): «в отступах» только для ведущих пробелов; общий «табы
  запрещены» — для таба между токенами/в строке. SPEC §2: «табы запрещены везде».
- **L-5 vs L-6** — два РАЗНЫХ текста: голый «незакрытый строковый литерал» при EOF до кавычки;
  уточнённый «(перевод строки внутри строки запрещён)» при `\n` внутри литерала.
- **L-8** — это ошибка ФОРМЫ числа (`_` не между цифрами, двойной `_`) и применяется ТОЛЬКО к лексемам,
  начинающимся с ЦИФРЫ. Лексема с ведущим `_` — это IDENT (FR-012), не число, и L-8 для неё невозможна.
  **Переполнение int64-литерала
  НЕ здесь** — это статическая ошибка ПАРСЕРА «целочисленный литерал вне диапазона типа Целое
  '<лексема>'» (§13.4, категория Синтаксическая), не лексическая (D2/B2, guardrail 1). Числовую
  величину `DURATION` лексер тоже не проверяет на диапазон (FR-017).
- **L-9** — run читается жадно ЦЕЛИКОМ; нельзя дробить на валидный суффикс + хвост.
- **L-10** — `!` валиден только как часть `!=`; одиночный `!` → L-10 с `'!'`.
- **L-11** — токен НЕ эмитится (FR-013); регистрируется только ошибка.
- **Общее правило (panic-mode, вариант a)** — при ЛЮБОЙ лексической ошибке проблемная лексема
  пропускается (токен для неё НЕ эмитится), а скан остатка логической строки продолжается штатно:
  валидные токены после ошибки попадают в поток. L-11 («токен не эмитится») — ЧАСТНЫЙ случай этого
  общего правила, а не исключение из него.

## Канон позиционирования и накопления

- Все позиции — в **рунах** (на кириллическом префиксе колонка = рунный индекс, не байтовый; SC-002,
  US2.10).
- Panic-mode: после ошибки подавляется ТОЛЬКО регистрация НОВЫХ ошибок до точки синхронизации (конец
  логической строки), без каскада фантомов; токены остатка строки при этом ЭМИТЯТСЯ штатно (best-effort,
  C-1.6). Накопитель ≈20 (FR-025, SC-005). Лексер НЕ печатает «Найдено K ошибок.» (FR-026) — это
  слой-потребитель.

## Каноны, которые лексер НЕ порождает (границы)

- `целочисленный литерал вне диапазона типа Целое '<лексема>'` — **парсер** (Синтаксическая, §13.4).
- Незакрытые скобки/блоки, неожиданный токен, цепочечные сравнения — **парсер**.
- Предупреждения («Предупреждение в строке N, колонка M:») — тип зарезервирован (FR-004), но лексер
  их НЕ порождает.
