## Phase 3: User Story 1 — Выражения с приоритетами и раздельной арифметикой (Priority: P1) 🎯 MVP

**Goal**: `evalExpr` вычисляет дерево от парсера (приоритеты не переразбираются, слева направо): литералы, унарные, бинарные (арифметика §3.3 / сравнения / короткозамкнутая логика), индексация в рунах. Раздельны `Целое`/`Дробное`.

**Independent Test**: подать таблицу выражений → сверить значение и тип; инварианты `2+3*4`→`Целое 14`; `7/2`→`Дробное 3.5`; `2<3 и 3<4`→истина; короткое замыкание не вычисляет правый операнд.

- [X] T015 [US1] `evalExpr(env, e)` — type switch по **указательным** узлам + литералы (`IntLit`→`Целое`, `FloatLit`→`Дробное`, `StringLit`→`Строка`, `BoolLit`→`Булево`, `NoneLit`→`None`, `ListLit`→новый `Список` слева направо) + `Ident`→`env.Lookup` в `internal/eval/expr.go` + табличный тест `expr_test.go`. (Промах `Ident` пока даёт `ОшибкаВыполнения «'x' не объявлено»`; уточнение «функция-как-значение» — T033.)
- [X] T016 [US1] Унарные в `internal/eval/arith.go`: `OpNeg`(`-`) над `Целое`(с проверкой переполнения int64)/`Дробное`, иначе `TY-NEG «унарный '-' нельзя применить к <тип>»`; `OpNot`(`не`) над `Булево`, иначе `TY-NOT «'не' нельзя применить к <тип>»`; позиция = `UnaryExpr.Pos()` + тесты в `arith_test.go`.
- [X] T017 [US1] Бинарная арифметика §3.3 в `internal/eval/arith.go`: `+ - *` `Цел○Цел`→`Целое` с **явной** проверкой переполнения (`RT-OVERFLOW`), промоушен при `Дробное`; `/`→**всегда** `Дробное`; `//` только `Цел//Цел`→`Целое` (иначе `ОшибкаТипа`); `%` `Цел%Цел`→`Целое`/`Дроб%Дроб`→`Дробное` (`math.Mod`), смешанное→`ОшибкаТипа`; правый операнд `/`/`//`/`%`=0→`RT-DIV-ZERO «деление на ноль»` на позиции **оператора**; `Строка+Строка`→конкатенация; прочее→`TY-ADD`/`TY-BINOP`; списки `+` НЕ складываются. Тесты: `2+3*4`=14, `7/2`=3.5, `6/2`=3.0, `9223372036854775807+1`→переполнение, `1/0`→деление на ноль (поз. оператора).
- [X] T018 [US1] Сравнения и логика в `internal/eval/arith.go` (использует `value.equal`/порядок T008): `==`/`!=` над любыми типами; `< <= > >=` только взаимно-упорядочиваемые (иначе `TY-BINOP`); `или`/`и` **короткозамкнуты**, оба операнда строго `Булево` (`TY-LOGIC «'<оп>' требует Булево, получено <тип>»`), результат строго `Булево` (НЕ возврат операнда); позиция = `BinaryExpr.Pos()`. Тесты: `1==1.0`→истина, `[1,2]==[1,2]`→истина, `"а"<"б"`→истина, `ложь и (1/0==0)`→ложь без вычисления правого, `истина или (1/0==0)`→истина.
- [X] T019 [US1] `IndexExpr` в `internal/eval/expr.go`: `Список`→элемент, `Строка`→руна (**индексация в рунах**); `index` обязан `Целое` (иначе `TY-INDEX-TYPE`); вне `[0,длина)` вкл. отрицательные→`RT-INDEX-RANGE «индекс N вне диапазона (длина L)»`; иной `target`→`TY-INDEX-NONIDX`; позиция = `IndexExpr.Pos()` + тесты: `[10,20,30][1]`=20, `"привет"[0]`="п", `[1,2][5]`→ошибка.
- [X] T020 [US1] `FieldExpr` в `internal/eval/expr.go`: `Запись`→`Get(field)` (отсутствует→`None`); иной `target`→`TY-FIELD «значение типа <тип> не имеет полей»` (в чистом 003 — всегда, граница D5); позиция = `FieldExpr.Pos()` + тест.

**Checkpoint**: SC-004 (инварианты выражений) подтверждены табличными тестами; US1 тестируется автономно подачей AST в `evalExpr`.

## Phase 5: User Story 3 — Управляющие конструкции и циклы (Priority: P2)

- [X] T027 [US3] `IfStmt` в `internal/eval/stmt.go`: `Cond` — strict-`Булево` (не-`Булево`→`TY-COND «условие должно быть Булево, получено <тип>»` на `Cond.Pos()`); первая истинная ветвь→`evalBlock`; цепочка `ElseClause` по `IsFinal()` (различает финальный `иначе` и `иначе если`) + тесты.
- [X] T028 [US3] `WhileStmt` в `internal/eval/stmt.go`: перед каждой итерацией `Cond` (strict-`Булево`); тело→`evalBlock`; `SigBreak`→выход (поглощён), `SigContinue`→следующая итерация (поглощён), `SigReturn`→наверх + тесты.
- [X] T029 [US3] `ForStmt` (`для x в E`) в `internal/eval/stmt.go`: `E` обязан `Список` (иначе `TY-FOR «'для' требует Список, получено <тип>»` на `Iterable.Pos()`); `x` в **охватывающей** области — `Define` при первом элементе **если имени ещё нет**, затем `Assign`; пустой список→`x` не создаётся; после цикла `x` видна (последний элемент); на время цикла список помечается «итерируется» (снять по выходу/ошибке) + тесты. Сигналы как у `пока`.
- [X] T030 [US3] `BreakStmt`→`SigBreak`, `ContinueStmt`→`SigContinue`, `ReturnStmt`→`SigReturn{Value или None}` в `internal/eval/stmt.go` + тесты. (Легальность контекста — семпроход T042, не рантайм.)

- [X] T032 [US4] Резолв вызова в `internal/eval/call.go`: `CallExpr` с `Ident`-callee `f` по порядку — (1) переменная за `(`→`RT-NOT-FUNC «'f' — не функция (<тип>), вызов невозможен»`; (2) `funcs[f]`→пользовательская; (3) `builtins[f]` активная→вызов, deferred-заглушка→`SEM-DEFERRED-BUILTIN`; (4) иначе→`SEM-FN-UNDECLARED «функция 'f' не объявлена»`; не-`Ident` callee→вычислить→«не функция»; позиция всех = `CallExpr.Pos()`.
