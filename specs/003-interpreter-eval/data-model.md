# Phase 1 — Data Model: Интерпретатор Ladix (tree-walking eval)

**Feature**: 003-interpreter-eval | **Date**: 2026-06-05 | **Plan**: [plan.md](./plan.md)

Описывает сущности новых пакетов `internal/value` и `internal/eval`, расширение `internal/errors` и структуры семпрохода. Поля описаны **концептуально** (контракт), без обязательных Go-сигнатур — те конкретизирует `/speckit-tasks`/реализация. Публичные Go-имена английские и идиоматичные, тексты сообщений русские, имена типов канонические (`Целое`/`Дробное`). Источник эскиза модели значений — ARCHITECTURE §5; поведения — `docs/eval-model.md §1–§10`. Ссылки «Guardrail N» — на [plan.md](./plan.md).

## 1. `value.Value` и 10 типов (`internal/value`) — модель значений

Интерфейс-тег + конкретные структуры; интерпретатор различает их type switch'ем. Ровно **10** типов; в 003 **конструируются 6**.

| Интерфейс | Контракт | Реализуют |
|---|---|---|
| `Value` | единственный метод `TypeName() string` — каноническое имя типа для `тип(x)` и сообщений `ОшибкаТипа` | все 10 конкретных типов |

| Тип (канон) | Go-представление | Конструируется в 003 | Семантика |
|---|---|---|---|
| `Целое` | `int64` | ✅ | переполнение в `+ - *` → `ОшибкаВыполнения`; литерал вне диапазона — статика парсера |
| `Дробное` | `float64` | ✅ | IEEE 754; ±Inf/NaN достижимы только переполнением float |
| `Строка` | `string` (UTF-8) | ✅ | неизменяемая; индексация `[i]` и `длина` — в **рунах** |
| `Булево` | `bool` | ✅ | условия strict — обязаны быть `Булево` |
| `Пусто` | синглтон `var None = Пусто{}` | ✅ | функция без `вернуть` и голый `вернуть` → именно `None`; отсутствующее поле `Записи` → `None` |
| `Список` | `*[]Value` (ссылочный) | ✅ | алиас делит хранилище (`пусть b = a`); мутатор `добавить` меняет `*Elems` на месте |
| `Запись` | `keys []string` + `fields map[string]Value` (открытая, порядок полей) | ❌ (смоделирована) | `Get`→`None` на отсутствующем; `Keys` для печати/итерации; равенство структурно; ссылочная |
| `Дата` | год-месяц-день, без времени | ❌ (deferred) | определён, не конструируется; источники — `дата()`/`сегодня()`… (deferred) |
| `Длительность` | пара `(int64, unit)` | ❌ (deferred) | `unit ∈ {Сек,Мин,Час,Дн,Нед,Мес}`; `1мес` не сводится к секундам |
| `Период` | enum из 5 констант | ❌ (deferred) | `ежедневно`…`ежегодно`; в 003 не предопределены |

**Инварианты**:

- Функция **не** является `Value` — не присваивается/не передаётся/не возвращается/не кладётся в список (Guardrail 2/3). Резолв функций — в отдельных таблицах (см. §8).
- 6 конструируемых: `Целое`/`Дробное`/`Строка`/`Булево`/`Пусто`/`Список`. `Запись` смоделирована полностью (читается, сравнивается, печатается), но в чистом 003 не порождается — `FieldExpr` всегда упирается в `«значение типа <тип> не имеет полей»` (Guardrail 2/16, D5).
- `Дата`/`Длительность`/`Период` определены в пакете как стабильная поверхность `eval↔store`, ни один путь кода 003 их не конструирует.
- Все 10 структур существуют сразу — нейтральная поверхность под будущий `store` (ARCHITECTURE §2.1, вариант A).

## 2. Строковое представление (`internal/value`, §7) — `строка(x)` / `печать`

Единое для `строка(x)` и `печать` (Guardrail 13, FR-030).

| Тип | Представление |
|---|---|
| `Целое` | десятичная (`42`, `-5`) |
| `Дробное` | `strconv.FormatFloat(v,'g',-1,64)`; если результат «выглядит целым» (нет `.`/`e`/`E`/`n`/`i`) → добавить `.0` (`2175` → `2175.0`); `3.14`→`3.14`; sci как у Go (`1e+20`) |
| `Строка` | сам текст **без кавычек** |
| `Булево` | `истина` / `ложь` |
| `Пусто` | `пусто` |
| `Список` | `[` элементы через `, ` рекурсивно `]` (`[1, две, истина]`) |
| `Запись` | `{` `поле: значение` через `, ` в порядке полей `}` |

**Правила**:

- Строки **внутри** `Список`/`Запись` печатаются без кавычек, как на верхнем уровне (различение строки от идентификатора — через `тип(x)`, не через вывод).
- Принудительная `.0` гарантирует визуальное отличие `Дробное` от `Целое`; требуется golden `функция.ladix` (`2175.0`).

## 3. Равенство и упорядочивание (`internal/value`, §3.3)

| Операция | Правило |
|---|---|
| `==` / `!=` | любые типы; разные типы → `ложь`, **кроме** `Целое↔Дробное` (численно: `1 == 1.0` → `истина`); `Строка` по код-поинтам; `Булево` по значению; `Пусто` равно только `Пусто`; `Список` поэлементно (разная длина → `ложь`); `Запись` структурно (множество полей + значения) |
| `< <= > >=` | только взаимно-упорядочиваемые: `Цел↔Цел`, `Дроб↔Дроб`, `Цел↔Дроб` (промоушен), `Строка↔Строка` (лексикографически по код-поинтам); прочее → `«'<оп>' нельзя применить к <тип> и <тип>»` |

**Инварианты/границы**: неявных приведений нет, кроме автопромоушена `Целое→Дробное` в арифметике/сравнениях. Списки `<` не сравниваются (только `==`/`!=`). `Запись` — только `==`/`!=` (структурно).

## 4. `Environment` (`internal/eval`) — область видимости

| Поле | Тип | Описание |
|---|---|---|
| `vars` | `map[string]value.Value` | привязки этой области (`пусть`, параметры, переменная `для`) |
| `parent` | `*Environment` | внешняя область (`nil` у глобала); связный список изнутри наружу |

| Метод | Контракт |
|---|---|
| `NewEnvironment(parent)` | создаёт область с данным `parent` |
| `Define(name, v)` | новая привязка в **этой** области; повтор → ловится семпроходом (`«'x' уже объявлено в строке N»`) |
| `Assign(name, v)` | поиск существующей вверх по цепочке; не найдено → `«'x' не объявлено»` |
| `Lookup(name)` | чтение вверх по цепочке; `(value, bool)` |

**Правила** (Guardrail 3, D3):

- Новую область создают ТОЛЬКО (1) глобал и (2) кадр вызова функции; блоки `если/иначе/пока/для` своей области **НЕ** создают — тело исполняется в текущей области.
- Кадр функции: `parent = ГЛОБАЛЬНАЯ область` (лексическая, не динамическая видимость); рекурсия = независимые кадры, каждый `parent = global`.
- Следствие: `пусть категория` в обеих ветках `если/иначе` → «уже объявлено»; `категория = …` в ветке мутирует внешнюю переменную.

## 5. `Signal` / `SignalKind` (`internal/eval`) — штатный поток управления

| Тип | Значения / поля | Назначение |
|---|---|---|
| `SignalKind` | `SigNormal`, `SigBreak`, `SigContinue`, `SigReturn` | вид штатного сигнала |
| `Signal` | `Kind SignalKind`; `Value value.Value` | `Value` значим **только** при `SigReturn` |

**Поведение** (Guardrail 8, D4):

- Два независимых канала: `error` (рантайм-ошибки, всплывают немедленно до CLI) и `Signal` (штатный поток, НЕ panic/recover).
- `evalBlock`: после каждого statement — `err≠nil` → наверх; `sig.Kind≠SigNormal` → прекратить блок и вернуть сигнал.
- Цикл (`пока`/`для`) ловит `SigBreak` (выход) и `SigContinue` (следующая итерация); `SigReturn` пробрасывает наверх.
- Вызов функции ловит `SigReturn` → его значение; `SigNormal` (дошли до конца тела) → `value.None`. `SigBreak`/`SigContinue` сюда дойти не могут (легальность — семпроход).

## 6. `Interpreter` (`internal/eval`) — состояние исполнения

| Поле | Тип | Описание |
|---|---|---|
| `global` | `*Environment` | глобальная область программы |
| `funcs` | `map[string]*ast.FunctionDecl` | пользовательские функции (из семпрохода, forward-вызовы) |
| `builtins` | `map[string]Builtin` | 23 активных + 12 deferred-заглушек |
| `maxDepth` | `int` | лимит глубины рекурсии (флаг `--max-depth`, по умолчанию 10000) |
| `depth` | `int` | текущая глубина пользовательских вызовов (`++`/`defer --`) |
| `out` | `io.Writer` | канал вывода `печать` (инжектируется; тест — `bytes.Buffer`) |

**Инварианты** (Guardrail 5/11/12/17, FR-021):

- Состояние передаётся явно, без глобалов (конституция V); `out` инжектируется.
- Резолв вызова: переменные (`Environment`) → `funcs` → `builtins` → `«функция 'f' не объявлена»`.
- `depth > maxDepth` → `ОшибкаВыполнения «превышена максимальная глубина вызовов (10000). Возможна бесконечная рекурсия.»` (число = фактический лимит).

## 7. `Builtin` (`internal/eval`) — запись встроенной функции

| Поле | Тип | Описание |
|---|---|---|
| `Name` | `string` | имя для резолва/затенения/сообщений |
| `Arity` | дескриптор арности | фикс. `N` / вариативная / перегруженная (по типу или по арности) |
| `Fn` | вызываемое | реализация (получает вычисленные аргументы + контекст интерпретатора для `out`/`store`-границы) |

**Правила** (Guardrail 12, D6 — полный реестр в [contracts/builtins.md](./contracts/builtins.md)):

- РОВНО **23** активных + **12** deferred-заглушек (закрытый список; расширять/сокращать ЗАПРЕЩЕНО). `длина` в счёте ×1.
- Фикс. арность проверяется семпроходом; вариативные/перегруженные (`печать`/`диапазон`/`длина`) — в рантайме (`«'имя': неверное число аргументов»`).
- `печать` — единственный канал вывода (в `out`); `добавить` — единственный мутатор; прочие списочные возвращают новый список; типы аргументов на семпроходе не проверяются.
- Все встроенные затеняемы `пусть` того же имени (с предупреждением, не ошибка).
- deferred-заглушка при вызове → `СемантическаяОшибка «функция '<имя>' не поддерживается в этой версии»`.

## 8. Два пространства имён (резолв) — переменные vs функции

| Пространство | Носитель | Содержимое |
|---|---|---|
| Переменные | `Environment` (§4) | `пусть`-привязки, параметры, переменная `для` |
| Функции | `funcs` + `builtins` (§6/§7) | пользовательские `FunctionDecl` + 23 активных + 12 deferred-заглушек |

**Правила** (Guardrail 10, D8, §5.2):

- Имя в позиции значения (Ident не под вызовом): резолв в `Environment`; промах, но есть в таблице функций → `«'имя' — функция, её нельзя использовать как значение»`; иначе → `«'x' не объявлено»`.
- `CallExpr` с `Ident`-callee `f`: (1) переменная за `(` (в v1 никогда не функция) → `«'f' — не функция (<тип>), вызов невозможен»`; (2) `funcs[f]` → вызов; (3) `builtins[f]` активная → вызов, deferred → «не поддерживается»; (4) → `«функция 'f' не объявлена»`. Не-`Ident` callee → вычислить → `«… — не функция (<тип>)»`. Позиция всех = `CallExpr.Pos()`.

## 9. Категории ошибок (`internal/errors`) — расширение

Три новых листовых типа по образцу `LexError`/`ParseError` (1 тип = 1 файл, метод-**значение** `Error()`, дружат с `errors.As`).

| Тип (категория) | Стадия | Поля | Источники |
|---|---|---|---|
| `СемантическаяОшибка` | 3 (семпроход) | `Pos Position`; `Msg string` | повтор объявления, фикс. арность, контекст `вернуть`/`прервать`/`продолжить`, необъявленная функция, deferred-конструкции/встроенные |
| `ОшибкаТипа` | 4 (исполнение) | `Pos Position`; `Msg string` | несовместимые операнды бинарных/унарных, условие не-`Булево`, `для` не над `Список`, индекс/поле неверного типа, ошибки преобразования стдлиб |
| `ОшибкаВыполнения` | 4 (исполнение) | `Pos Position`; `Msg string` | деление на ноль, переполнение, индекс вне диапазона, лимит рекурсии, рантайм-стдлиб, функция-как-значение/не-функция, period-имя «не объявлено» |

**Инварианты/границы** (Guardrail 14, FR-031/032/033):

- Формат двухстрочный: `Ошибка в строке N, колонка M:` + перевод строки + `Msg`; `N`/`M` с 1, `M` в **рунах**.
- eval — **fail-fast**: накопителя нет (`ErrorList` остаётся артефактом лексера/парсера).
- Листовость `errors` сохраняется: типы НЕ импортируют `ast`/`value`; `<тип>` подставляет вызывающий eval через `value.TypeName()`, позицию — из `ast.Pos()`.
- Полезная нагрузка — ДОСЛОВНО из §8.3 (без точки, кроме многофразовых). Полный каталог — в [contracts/runtime-errors.md](./contracts/runtime-errors.md).

## 10. `Analyze` (`internal/eval`) — семантический проход (стадия 3)

`Analyze(prog *ast.Program) error` — лёгкий **fail-fast** обход AST до исполнения (первая ошибка или `nil`, накопителя нет).

| Шаг | Что делает |
|---|---|
| Шаг 1 — регистрация деклараций | все top-level `FunctionDecl` → `funcs` (forward-вызовы разрешены); повтор имени → `«функция 'f' уже объявлена в строке N»`; top-level декларатив (`источник`/`метрика`/`процесс`/`триггер`) → deferred-ошибка |
| Шаг 2 — обход по областям (блоки область не открывают) | повтор `пусть x` в той же области (в т.ч. в разных ветках `если`, `для x` при объявленном `x`) → `«'x' уже объявлено в строке N»`; `вернуть` вне функции / `прервать`/`продолжить` вне цикла → соответствующий текст; `CallExpr`-`Ident` — резолв + проверка **фикс.** арности; reserved-узлы (`*Action`, `RunProcessExpr`) и `DurationLit` → deferred-ошибка |

**НЕ делает** (оставлено рантайму, Guardrail 15, FR-035): declaredness **переменной** в позиции значения (flow-зависимо); проверки **типов** (динамика); арность **вариативных/перегруженных** встроенных (`печать`/`диапазон`/`длина`).

## Сводка узлов и счёт

- **Пакет `internal/value`** (новый, листовой): интерфейс `Value` + **10** типов (6 конструируемых: `Целое`/`Дробное`/`Строка`/`Булево`/`Пусто`/`Список`; 1 смоделирован: `Запись`; 3 deferred: `Дата`/`Длительность`/`Период`) + строковое представление §7 + равенство/упорядочивание §3.3.
- **Пакет `internal/eval`** (новый): `Environment` (3 метода), `Signal`/`SignalKind` (4 вида), `Interpreter` (6 полей), `Builtin`, `Analyze` (2 шага); evalExpr/evalStmt/evalBlock + резолв вызова.
- **Пакет `internal/errors`** (расширение): **+3** типа (`СемантическаяОшибка`, `ОшибкаТипа`, `ОшибкаВыполнения`); `Position`/`LexError`/`ParseError`/`Warning`/`ErrorList` — без изменений.
- **Стдлиб**: **23** активных (вывод 1 + преобразование 6 + агрегаты 5 + списки 10 + строки 1) + **12** deferred-заглушек (дата/время 9 + процессные 3) = **35**.
- **Команда `cmd/ladix`** (новая): `run` + флаг `--max-depth`, recover-барьер, коды 0/1/2.
- **AST-вход** (потребляется, не меняется): выражения — `BinaryExpr`/`UnaryExpr`/`CallExpr`/`IndexExpr`/`FieldExpr`/`IntLit`/`FloatLit`/`StringLit`/`BoolLit`/`NoneLit`/`ListLit`/`Ident`; statements — `LetStmt`/`AssignStmt`/`ExpressionStmt`/`IfStmt`/`WhileStmt`/`ForStmt`/`ReturnStmt`/`BreakStmt`/`ContinueStmt`; декларация — `FunctionDecl`; reserved/deferred — `RunProcessExpr`/`DurationLit`/`AssignAction`/`CallAction`/`NotifyAction`; вспомогательные — `Block`/`ElseClause`.
