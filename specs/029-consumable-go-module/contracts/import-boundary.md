# Contract: Страж границы фронтенд↔backend (import-boundary)

Контракт теста-стража `boundary_test.go` (живёт в **корневом пакете** `ladix`). Машинно
гарантирует, что публичное замыкание потребителя НЕ тянет тяжёлую/запрещённую зависимость
(Принцип VII ред. 1.1.0). Реализует FR-009 / FR-010; подтверждает Acceptance A4 / SC-003.

## Назначение

Потребитель (платформа «Уклад», вариант B) импортирует только `ladix` и `ir`. Сборка
Уклада **не должна** транзитивно затягивать `modernc.org/sqlite`, движок процессов, демон и
SQLite-стор. Страж делает этот инвариант проверяемым в CI, а не «на честном слове».

## Семантика границы (НЕ противоречить!)

- **Запрещены в публичном замыкании** (прямо или транзитивно):
  `modernc.org/sqlite` И пакеты `internal/store`, `internal/engine`, `internal/daemon`.
- **Фасад `ladix` ЗАВИСИТ от `internal/eval`** — и это **ОК**. `eval` вызывается ради
  семантической валидации (`Analyze`) и понижения в IR. `eval` **sqlite-free**: импортирует
  только `ast` / `value` / `errors` (и не тянет store/engine/daemon). Поэтому `internal/eval`
  и `internal/jsonval` ДОПУСТИМЫ в замыкании `ladix` (`jsonval` зависит только от `value`).
- Итог формулировки: запрет касается **ровно** `internal/{store,engine,daemon}` +
  `modernc.org/sqlite`. Присутствие `internal/eval`/`internal/jsonval` в замыкании `ladix`
  нарушением НЕ является.
- **Для пакета `ir`** замыкание должно быть **минимальным**: только stdlib (+ возможно
  `value`), БЕЗ `internal/eval`. `ir` — чистый контракт данных, исполнитель ему не нужен.

## Механика

Тест на `os/exec` запускает `go list -deps <pkg>` для проверяемых публичных пакетов,
собирает множество транзитивных зависимостей и проверяет отсутствие запрещённых.

```go
func deps(t *testing.T, pkg string) map[string]bool {
    out, err := exec.Command("go", "list", "-deps", pkg).Output()
    // ... разбор по строкам в множество
}
```

Имя модуля — `github.com/denis-kosyakov/ladix` (без сегмента `/src`).

**Проверяемые публичные пакеты:**

| Пакет | Обязателен | Роль |
|-------|-----------|------|
| `github.com/denis-kosyakov/ladix` (корень) | **да** | точка входа потребителя (фасад) |
| `github.com/denis-kosyakov/ladix/ir` | **да** | версионируемый контракт вывода |

Публичная поверхность **исчерпывается** этими двумя пакетами (FR-003): `lexer`/`parser`/`ast`/
`value`/`errors` остаются под `internal/` и потребителю недоступны, поэтому в список стража
не входят. Страж перечисляет пакеты **явно** — если поверхность позже расширится аддитивно,
новый пакет добавляется в список этим же контрактом.

## Замки

| ID | FR | Что пинит | Проверяемый пакет | Ассерт (FAIL-условие) |
|----|----|-----------|-------------------|------------------------|
| **T1** | FR-009/FR-010 | замыкание фасада без SQLite | `ladix` (корень) | `deps(ladix)` НЕ содержит `modernc.org/sqlite`; (eval/jsonval — допустимы) |
| **T2** | FR-009/FR-010 | минимальное замыкание `ir` | `ir` | `deps(ir)` НЕ содержит `modernc.org/sqlite` И ни одного из `internal/{store,engine,daemon}` И `internal/eval` |
| **T3** | FR-009 | ни один публичный пакет не тянет backend | `ladix`, `ir` (публичная поверхность целиком, FR-003) | для каждого: замыкание НЕ содержит `internal/store`, `internal/engine`, `internal/daemon` |

T1 намеренно мягче T3 по `internal/eval`: фасад `ladix` тянет `eval` легитимно (sqlite-free),
поэтому T1 запрещает только `modernc.org/sqlite`. T2 для `ir` — строгое минимальное замыкание.

## Мутстратегия (как краснеет)

- Добавить `import _ "github.com/denis-kosyakov/ladix/internal/store"` в любой публичный
  пакет (`ladix` / `ir`) → **T3 краснеет** (а если это `ir` — ещё и **T2**).
- Если `internal/eval` начнёт тянуть `internal/store` (регресс разрыва `ProcessRuntime`/границы
  eval↔store) → `store` транзитивно протечёт в замыкание `ladix` через `eval`, а `store` тянет
  `modernc.org/sqlite` → **T1 краснеет** (и T3 на `ladix`).
- Затащить `internal/eval` в `ir` → **T2 краснеет**.

## Бюджет

- **0 новых внешних зависимостей** теста: только stdlib `os/exec`, `testing` (+ `strings`/
  `bufio` для разбора). (FR-019)
- Тест запускается из **корня** репозитория (новая раскладка `go.mod` в корне).
